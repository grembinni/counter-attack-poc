<objective>
Reverse a deliberate Phase 47 design choice in draft mode: the eligible-target highlight must
itself respect the GK slot rule (slot 0 requires a GK card; a GK card fits only slot 0), instead
of highlighting every slot and rejecting with a message after the click.

Purpose: live user testing of the just-shipped Phase 47 confirmed the highlight-everything-then-reject
behaviour is wrong UX. The highlight must tell the truth about where a card can legally go.
Output: a one-line predicate change in `isDraftSlotEligible`, removal of the now-unreachable
client-side reject-with-message helpers, and six draft-mode tests replacing the one test that
asserted the old (now reversed) behaviour.
</objective>
