### SVG Piece Color System — Phase 20 Parameterized Palette

Phase 20 replaces all hardcoded per-team SVG colors with the 4-color `TeamPalette`. The following contract defines every color role used by the 12 uniform styles.

**Source:** CONTEXT.md decisions D-01 through D-13 + `teamConfig.ts` palette values.

#### Active Team Palettes (City and Crew)

| Team | `primary` | `primaryLight` | `secondary1` | `secondary2` |
| ---- | --------- | -------------- | ------------ | ------------ |
| City | `#dc143c` | `#f87171`      | `#f5c518`    | `#1e1e2e`    |
| Crew | `#f5c518` | `#fde68a`      | `#111111`    | `#14532d`    |

_(Values sourced from `COLOR_SCHEME_REGISTRY` in `teamConfig.ts` — Phase 19 output.)_

#### GK Palette Swap Rule (D-13)

When `isGK = true`, the renderer applies a full palette inversion before passing colors to the style function:

| Original role  | GK role                |
| -------------- | ---------------------- |
| `primary`      | becomes `secondary1`   |
| `primaryLight` | becomes `secondary2`   |
| `secondary1`   | becomes `primary`      |
| `secondary2`   | becomes `primaryLight` |

No separate GK style definitions exist. Every outfield style auto-generates a GK variant via this swap.

## SVG Pattern Technical Contract

This section provides the executor with prescriptive SVG geometry for each style.

### Pattern Anchor Convention (existing — must preserve)

```
patternUnits="userSpaceOnUse"
x={cx - PIECE_RADIUS}   // = cx - 12
y={cy - PIECE_RADIUS}   // = cy - 12
```

All `<pattern>` elements use this anchor. `linearGradient` uses `gradientUnits="userSpaceOnUse"` with the same cx/cy bounds.

### ID Naming Convention

Pattern IDs must be unique per piece to avoid SVG defs collisions:

```
id={`${uniformStyle}-${piece.id}`}          // outfield pattern
id={`${uniformStyle}-gk-${piece.id}`}       // GK (after palette swap)
id={`grad-${uniformStyle}-${piece.id}`}     // linearGradient (fade style)
id={`clip-${uniformStyle}-${piece.id}`}     // clipPath (diagonal, corners styles)
```

### Style-Specific Geometry

#### `pinstripe` — 8×24px tile

```svg
<pattern width={8} height={24} ...>
  <rect width={8} height={24} fill={palette.primary} />
  <rect x={2} y={0} width={4} height={24} fill={palette.primaryLight} fillOpacity={0.9} />
</pattern>
```

_(Matches existing city-jersey pattern exactly — only colors are parameterized.)_

#### `diagonal` — clipPath + sibling line overlay

```svg
<clipPath id={`clip-diagonal-${piece.id}`}>
  <circle cx={cx} cy={cy} r={PIECE_RADIUS} />
</clipPath>
<!-- circle fill: palette.primary -->
<line
  x1={cx - PIECE_RADIUS} y1={cy - PIECE_RADIUS}
  x2={cx + PIECE_RADIUS} y2={cy + PIECE_RADIUS}
  stroke={palette.secondary2}
  strokeWidth={10}
  strokeOpacity={0.8}
  clipPath={`url(#clip-diagonal-${piece.id})`}
  pointerEvents="none"
/>
```

_(Matches existing Crew diagonal line approach — `secondary2` parameterizes the stroke.)_

#### `checker` — 12×12px tile

```svg
<pattern width={12} height={12} ...>
  <rect width={12} height={12} fill={palette.primary} />
  <rect x={0} y={0} width={6} height={6} fill={palette.secondary1} />
  <rect x={6} y={6} width={6} height={6} fill={palette.secondary1} />
</pattern>
```

_(Matches existing home-gk-checker pattern exactly — colors parameterized.)_

#### `cosmos` — 24×24px tile

```svg
<pattern width={24} height={24} ...>
  <rect width={24} height={24} fill={palette.primary} />
  <rect x={0} y={6} width={24} height={12} fill={palette.secondary1} fillOpacity={0.85} />
</pattern>
```

_(Matches existing cosmos-jersey pattern exactly — colors parameterized.)_

#### `fade` — linearGradient

```svg
<linearGradient id={`grad-fade-${piece.id}`}
  gradientUnits="userSpaceOnUse"
  x1={cx - PIECE_RADIUS} y1={cy - PIECE_RADIUS}
  x2={cx + PIECE_RADIUS} y2={cy + PIECE_RADIUS}>
  <stop offset="0%" stopColor={palette.primary} />
  <stop offset="50%" stopColor={palette.primary} stopOpacity={0.5} />
  <stop offset="100%" stopColor={palette.secondary1} />
</linearGradient>
<!-- circle fill: url(#grad-fade-${piece.id}) — no pattern element -->
```

#### `tree-rings` — overlay circles (not a pattern)

PIECE_RADIUS=12. Rings: 3 concentric circles at radii 12, 8, 4 — alternating `primary` / `primaryLight`. Rendered as `overlay` (sibling elements after the base circle), `pointerEvents="none"`.

```
Ring 1 (outermost): r=12, fill="none", stroke=primary, strokeWidth=3
Ring 2:             r=8,  fill="none", stroke=primaryLight, strokeWidth=3
Ring 3 (innermost): r=4,  fill=primary  (solid dot center)
```

Base circle fill: `primary`.

#### `polka-dots` — 10×10px tile

```svg
<pattern width={10} height={10} ...>
  <rect width={10} height={10} fill={palette.primary} />
  <circle cx={5} cy={5} r={2.5} fill={palette.secondary1} />
</pattern>
```

#### `plus` — overlay rect cross (not a pattern)

Circle fill: `palette.secondary2`. Overlay cross (sibling `<rect>` elements after the base circle):

```
Horizontal bar: x=cx-7, y=cy-2.5, width=14, height=5, fill=primary, pointerEvents="none"
Vertical bar:   x=cx-2.5, y=cy-7, width=5, height=14, fill=primary, pointerEvents="none"
```

_(Clip to circle not required — bars are short enough to fall inside PIECE_RADIUS=12.)_

#### `v-stripe` — 24×24px tile

```svg
<pattern width={24} height={24} ...>
  <rect width={24} height={24} fill={palette.secondary1} />
  <!-- V-shape: two diagonal rects converging at bottom center -->
  <polygon points="0,0 8,0 12,12 4,12" fill={palette.primary} />
  <polygon points="16,0 24,0 20,12 12,12" fill={palette.primary} />
</pattern>
```

#### `quarters` — 24×24px tile

```svg
<pattern width={24} height={24} ...>
  <rect width={24} height={24} fill={palette.secondary2} />          <!-- BL quadrant baseline -->
  <rect x={0} y={0} width={12} height={12} fill={palette.primary} /> <!-- TL -->
  <rect x={12} y={0} width={12} height={12} fill={palette.secondary1} /> <!-- TR -->
  <rect x={12} y={12} width={12} height={12} fill={palette.primary} />   <!-- BR -->
</pattern>
```

#### `corners` — clipPath + polygon overlays

Circle fill: `palette.secondary1`. Corner triangles clipped to circle:

```
clipPath: circle cx={cx} cy={cy} r={PIECE_RADIUS}
TL triangle: points="{cx-12},{cy-12} {cx},{cy-12} {cx-12},{cy}"
TR triangle: points="{cx+12},{cy-12} {cx},{cy-12} {cx+12},{cy}"
BL triangle: points="{cx-12},{cy+12} {cx},{cy+12} {cx-12},{cy}"
BR triangle: points="{cx+12},{cy+12} {cx},{cy+12} {cx+12},{cy}"
All triangles: fill={palette.primary}, clipPath=url(#clip-corners-${piece.id}), pointerEvents="none"
```

#### `solid` — no pattern

Circle fill: `palette.primary`. No `<defs>`. Simplest renderer — returns `{ patternDef: null, fill: palette.primary, overlay: null }`.

  cy: number;

export const UNIFORM_STYLES: Record<UniformStyleId, UniformStyleRenderer> = { ... };
