<objective>
Create the client-side renderer registry `packages/client/src/styles/uniformStyles.tsx`: 12 `UniformStyleRenderer` functions and the `UNIFORM_STYLES: Record<UniformStyleId, UniformStyleRenderer>` map. Each renderer takes `{ cx, cy, R, palette, isGK, pieceId }` and returns `{ patternDef, fill, overlay }` — pure palette-parameterized SVG fragment descriptors. Add a colocated unit test proving all 12 styles exist, return the correct shape, and produce piece-unique ids.

Purpose: This is the parameterized rendering engine that replaces PieceOverlay's 6 hardcoded pattern blocks. Building it as an isolated registry (Wave 2) lets Wave 3 (PieceOverlay refactor) simply delegate to it.

Output: `uniformStyles.tsx` (12 renderers + registry) and `uniformStyles.test.tsx`. This satisfies UNIFORM-01's "each style defines an outfield rendering" — the GK variant is produced by the caller's palette swap in Plan 20-03, not by separate GK renderers (D-13).
</objective>
