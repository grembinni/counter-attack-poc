- **LONG_BALL accuracy type**: Uses `LONG_SAME_THIRD` (threshold 9) rather than `LONG_CROSS_THIRD` (threshold 10); the handler will determine the correct type when it has pitch region knowledge (plan 08.2-04)
- **Phase after LOOSE_BALL**: Returns `phase: 'PASS'` per D-23/D-24 locked decisions; movement restriction for unclaimed ball is enforced by ELIGIBLE_NEXT_ACTIONS['DEFLECTION'], not by hardcoding MOVEMENT
- **FIRST_TIME_PLAYER_MOVES deferred**: Added TODO comment in FIRST_TIME_PASS branch for Phase 8.3 per CONTEXT.md Claude's Discretion
- **Interception dice fallback**: `preGeneratedInterceptionDice?.[i] ?? 3` — default 3 if dice array is short
