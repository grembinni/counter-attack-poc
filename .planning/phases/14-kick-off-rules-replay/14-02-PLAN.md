<objective>
Implement REPLAY-06: make the ball marker position correct on every replay frame. Add a required `ballAfter` field to every replay-eligible ActionEvent union member, populate it at every event-creation site in gameEngine.ts (the TypeScript compiler enumerates each site once the type is required), and replace the GOAL-only ball update in buildReplayFrames with a universal `event.ballAfter`-driven update.

Purpose: Today the replay only moves the ball on GOAL events, so frames between passes, shots, and loose balls show a stale ball location. Recording the authoritative ball state on each event and replaying it fixes every stale-ball frame.
Output: Extended ActionEvent type, migrated event-creation sites, a universal ball update in buildReplayFrames, and migrated test event literals.
</objective>
