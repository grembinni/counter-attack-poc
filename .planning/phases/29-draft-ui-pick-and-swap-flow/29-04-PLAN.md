## Trust Boundaries

| Boundary                                      | Description                                                                                                       |
| --------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| client → DRAFT_PICK / DRAFT_REARRANGE handler | Untrusted card id, destination, and any slot claim cross here; server is the sole authority on legality and state |
| reconnect handshake → private draft view      | The reconnecting socket must receive only its own pack, never the opponent's                                      |
| server RNG → pack assignment & bench numbers  | Fairness-affecting randomness must be CSPRNG at the call site                                                     |
