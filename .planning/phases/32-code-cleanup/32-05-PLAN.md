<objective>
CLEANUP-03: Produce the standalone `SELECTOR-REVIEW.md` deliverable (D-05) cataloging every selector and derived-and-stored field in the 952-line `useGameStore.ts`, then FIX every real staleness/redundancy problem it surfaces in this same phase (D-06) — the success criterion is a fixed end-state confirmed by a documented review, not a findings backlog. Output: `SELECTOR-REVIEW.md` with every verdict resolved, and `useGameStore.ts` fixes applied for each "fix" verdict, with store tests green.
</objective>
