Purpose: The repo has never had hook-dependency linting; `App.tsx`'s single mount-once socket-registration effect closes over ~14 setters with an empty deps array. Enforcing exhaustive-deps at `error` catches the whole class of stale-closure bugs going forward.
Output: react-hooks rule enabled at error for the client; all violations fixed (stable-dep additions preferred); a reviewed checklist of any suppressions.
</objective>
