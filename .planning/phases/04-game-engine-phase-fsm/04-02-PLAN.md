<objective>
Create `packages/server/src/gameEngine.ts` — the socket.io-free pure-function core of Phase 4. It builds the initial GameState when both players are present, applies validated moves, advances the 4-5-2 FSM slot sequence, applies undo within the locked decision boundaries, and sets the MOVE-06 free-move state. All functions return discriminated-union results and never mutate the input state.

This is Wave 2 — depends on Wave 1's shared types/data (ActionEvent, RefereeCard, MovementSlot, HOME_SQUAD/AWAY_SQUAD, PITCH_REGIONS). Wave 3 wires these functions to socket handlers.

Purpose: ARCH-01 server-authority requires all FSM transitions and state mutations to live server-side as testable pure logic. Keeping the engine socket-free (the established Phase 2/3 pattern) means it is unit-tested without a server harness.
Output: gameEngine.ts (pure functions), gameEngine.test.ts (unit, Wave 0 stub turned green), and the game.integration.test.ts skeleton (lifecycle harness + setupRoom helper, scenarios filled in Wave 3).
</objective>
