## Trust Boundaries

| Boundary                                    | Description                                                                                                                                                      |
| ------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| store emitter → socket                      | `emitRosterReposition` is the client's only path to `GAME_ROSTER_REPOSITION`, but a modified client can emit the event directly; the server gates it regardless. |
