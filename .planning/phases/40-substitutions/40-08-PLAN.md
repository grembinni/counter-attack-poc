<objective>
Wire the real second-injury forced-substitution trigger (D-11) into the exact place
Phase 39 left a documented hook, replacing its unconditional "no substitute available"
fallback with a genuine availability check.

Purpose: Phase 39 shipped INJURY-03 with the forced-substitution branch deliberately
stubbed — `resolveFoulChain` always degrades the victim's attributes and leaves them on
the pitch, with a comment naming Phase 40 as the owner of the real check
(`gameEngine.ts` ~828-831, 39-CONTEXT.md D-06). Now that `applySubstitution`, the bench
and the substitution counters exist, that branch becomes conditional: substitute when a
substitute exists, degrade only when one does not.

RESEARCH.md Pitfall 5 is the governing constraint — this plan must NOT build a parallel
injury-substitution pathway. The forced substitution routes through the same
`applySubstitution` that a manager-initiated substitution uses, so every SUB-02..07 rule
is enforced identically. The single, explicitly-scoped relaxation is SUB-01's
stoppage-phase window, which exists to gate _manager_ availability and cannot apply to a
server-initiated swap fired mid-`MOVE` resolution.

Output: an `options.forced` escape hatch on `applySubstitution` (documented as
narrow-by-construction), a deterministic bench-picker, the rewired trigger, and an engine
test file that pins both the trigger and the surviving fallback.
</objective>
