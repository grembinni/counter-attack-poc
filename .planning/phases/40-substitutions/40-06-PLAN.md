## Trust Boundaries

| Boundary                     | Description                                                                     |
| ---------------------------- | ------------------------------------------------------------------------------- |
| rendered modal → socket emit | The modal decides what to offer; the server independently decides what is legal |
| own-team scoping in the UI   | The modal must never present an actionable control over the opponent's squad    |

## STRIDE Threat Register

| Threat ID | Category               | Component                                      | Disposition | Mitigation Plan                                                                                                                                                                                                                          |
| --------- | ---------------------- | ---------------------------------------------- | ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| T-40-19   | Elevation of Privilege | Modal data scoping                             | mitigate    | `midmatchPieces`, `bench`, `subsUsed` and `maxOnPitch` are all derived from `useMyTeam()`; the opposing team's pieces are filtered out before the component sees them, and the server re-checks ownership on every emit (40-05 T-40-15). |
| T-40-20   | Tampering              | Stale modal after a server-driven phase change | mitigate    | A `useEffect` force-closes the modal when `isStoppagePhase(phase)` becomes false, so the UI cannot keep offering an action the server would now reject; the server guard remains authoritative either way.                               |
