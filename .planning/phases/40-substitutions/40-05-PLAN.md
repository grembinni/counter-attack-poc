## Trust Boundaries

| Boundary                            | Description                                                                                       |
| ----------------------------------- | ------------------------------------------------------------------------------------------------- |
| client socket → `GAME_SUBSTITUTION` | Fully untrusted: any connected socket can emit any payload at any time, bypassing the UI entirely |
| handler → room state                | The handler is the only writer of `room.gameState` for this action                                |
