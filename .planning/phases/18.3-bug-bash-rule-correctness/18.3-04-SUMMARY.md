# Phase 18.3 Plan 04: BUG-14 / BUG-17 / BUG-18 Fix Summary

Three interlocking movement-phase state-machine bugs fixed: kick-off setup replay visibility (BUG-17), pace-exhaustion Snapshot availability (BUG-14), and Undo coverage across all move-bearing phases (BUG-18).

## What Was Built

### BUG-17: KICK_OFF_SETUP Replay Visibility

Added `'KICK_OFF_SETUP'` to `ActionEventType` and `ActionEvent` (mirrors MOVE shape: `pieceId/from/to/timestamp`, no `ballAfter`). The `GAME_KICK_OFF_MOVE` handler now logs one `KICK_OFF_SETUP` event per reposition atomically with the piece position update. `REPLAY_ELIGIBLE_TYPES` includes `KICK_OFF_SETUP`. `buildReplayFrames` has an explicit branch accumulating KICK_OFF_SETUP events into `moveGroup` (same batch-frame mechanism as MOVE). `ActionLog.tsx` has a `[SETUP]` case.

### BUG-14: Pace-Exhaustion Snapshot Availability

`computeMovedPieceIds` in `applyMove`: removed `paceExhausted` from the add condition — carrier is now locked into `movedPieceIds` **only** when `forceIncludeSelf` is true (i.e., when a different piece is activated — the `abandonedIds` path). `applyFreeMove`: removed the unconditional `if (paceExhausted) newMovedPieceIds.add(pieceId)` block. Removed unused variables `paceExhausted`, `effectivePace`, `rawPace`, `TESTING_PACE_OVERRIDE` from `applyMove`.

### BUG-18: Undo Coverage

**Fix 1 (regression):** `applyStartMovement` return now includes `lastDiceRoll: null` — clearing stale dice values so the client's `canUndo` guard (`if (lastDiceRoll) return false`) does not block Undo in MOVE.

**Fix 2 (coverage — lastDiceRoll audit):** `lastDiceRoll: null` added to all five newly-covered phase transitions:

- `applyGKKickTarget` return for `GK_KICK_MOVE`
- `applyDeclareShot` SNAPSHOT_TARGET→SNAPSHOT_DEFLECT transition
- `applyFreeMoveZoneCheck` FREE_MOVE_ATTACK/DEFENSE entry
- `triggerOffsideFoul` FREE_KICK_SETUP entry (in `offside.ts`)

**Fix 2 (coverage — eventLog gap):** Discovered that SNAPSHOT_DEFLECT and FREE_KICK_SETUP logged NO events for piece moves (prerequisite for Undo — deviation Rule 2):

- Added `SNAP_DEFLECT_MOVE` ActionEvent type; logged in the SNAPSHOT_DEFLECT move handler in `gameHandlers.ts`
- Added `FK_SETUP_MOVE` ActionEvent type; logged in both success paths of `applyFreeKickMove` (kicker placement and regular placement)

**applyUndo extended:**

- `moveTypeForPhase` now maps GK_KICK_MOVE→`'GK_KICK_MOVE'`, SNAPSHOT_DEFLECT→`'SNAP_DEFLECT_MOVE'`, FREE_KICK_SETUP→`'FK_SETUP_MOVE'`, FREE_MOVE_ATTACK/DEFENSE→`'MOVE'` (applyMove already emits MOVE there)
- `Extract` type cast extended to include the three new event types
- `lockReset` extended: GK_KICK_MOVE resets `gkKickMovedPieceId/gkKickPaceUsed`; SNAPSHOT_DEFLECT resets `snapDeflectMovedPieceId/snapDeflectPaceUsed`; FREE_KICK_SETUP restores `freeKickPlacedPieceIds` (removes undone piece)
- `validUndoPhases` in `gameHandlers.ts` extended to 8 phases (no KICK_OFF_SETUP)

**Fix 3 (client mirror):** `ActionPanel.tsx` `moveTypeForPhase` extended to match server mapping.

**ActionLog:** Added `SNAP_DEFLECT_MOVE` and `FK_SETUP_MOVE` cases to exhaustive switch.

**1. [Rule 2 - Missing Event Logging] SNAP_DEFLECT_MOVE event type added**

- **Found during:** Task 3 audit of newly-covered phases for eventLog gaps

- **Fix:** Added `SNAP_DEFLECT_MOVE` to `ActionEventType` + `ActionEvent` union; logged in the SNAPSHOT_DEFLECT move handler in `gameHandlers.ts` atomically with the piece position update. applyUndo extended to recognize it.

**2. [Rule 2 - Missing Event Logging] FK_SETUP_MOVE event type added**

- **Found during:** Task 3 audit of newly-covered phases for eventLog gaps
- **Issue:** `applyFreeKickMove` repositioned pieces without logging any event. Same consequence as SNAP_DEFLECT_MOVE — Undo would return NOTHING_TO_UNDO.
- **Fix:** Added `FK_SETUP_MOVE` to `ActionEventType` + `ActionEvent` union (includes `stageIndex` for stage context); logged in both success paths of `applyFreeKickMove` (kicker mandatory placement + regular placement). `lockReset` in applyUndo restores `freeKickPlacedPieceIds` on Undo.
- **Files modified:** `packages/shared/src/types.ts`, `packages/server/src/gameEngine.ts`, `packages/client/src/components/ActionLog.tsx`
