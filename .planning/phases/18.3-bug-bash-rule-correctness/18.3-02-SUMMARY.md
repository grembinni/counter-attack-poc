## Decisions Made

- **BUG-13 sequencing model**: The "second tackle" scenario is: a DEFENDER (D1) moves adjacent to the carrier; a SECOND DEFENDER (D2) is already stationary adjacent to the carrier. After D1's failed tackle, D2 gets an inline TACKLE_ATTEMPT. This is implemented as a scan of `newPieces` filtered by `hexDistance(p.position, carrier.position)===1` and not in `tackleAttemptedByIds`. D2's tackle die uses `3` fallback (one dice injection set per `applyMove` call per plan).

- **BUG-20 deferral mechanism**: Returning `state` UNCHANGED (not `{ ...state, ballZone: newZone }`) is the correct implementation. The PATTERNS.md suggested updating `ballZone` in the deferred return — but that would have silently prevented the free-move from EVER triggering for that crossing, because the next call would find `newZone === state.ballZone` (already updated) and return early. Stale `ballZone` is the correct "pending trigger" signal.

- **roomStore.ts unchanged**: The `broadcastState` call site requires no modification — the deferral guard lives inside the pure `applyFreeMoveZoneCheck` function as specified by the plan (ARCH-04 integrity maintained).

## Deviations from Plan

### Minor Investigation Adjustment

**1. [Rule 1 - Investigation] BUG-20 deferral: ballZone must NOT be updated**

- **Found during:** Task 3 (BUG-20 implementation)
- **Issue:** PATTERNS.md suggested `return { ...state, ballZone: computeBallZone(state.ball.position) }` in the deferred return, but this would silently prevent the zone-crossing trigger from ever firing — the next `applyFreeMoveZoneCheck` call would find `newZone === state.ballZone` (already synchronized) and exit via the early-return at line 1116 without triggering the free-move interrupt.
- **Fix:** Return `state` unchanged instead, preserving the stale `ballZone` value as the "pending trigger" signal. Confirmed by the "deferred trigger fires at PASS boundary" test.
- **Files modified:** packages/server/src/gameEngine.ts (deferral returns `state`, not `{ ...state, ballZone: ... }`)
