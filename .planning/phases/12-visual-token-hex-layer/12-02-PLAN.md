<objective>
Refactor HexCell to replace the free-form `isHighlighted: boolean` + `highlightColor?: string` props with a single typed `highlightType?: HexHighlightType` prop, moving all tint color values into an internal `HIGHLIGHT_STYLES` lookup table (single source of truth).

Purpose: UX-06 requires a unified, named hex-tint color system with five distinct semantic types. Owning the color table inside HexCell means colors change in exactly one place. This plan delivers the leaf component API so HexGrid (Plan 04) can priority-resolve one type per hex.

Output: Updated `HexCell.tsx` exporting `HexHighlightType` and `HIGHLIGHT_STYLES`, plus a new `HexCell.test.tsx`.
</objective>
