## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage                                       |
| ----- | ----- | ------------------------------------------- |
| xs    | 4px   | Inline icon gaps, SVG stroke hairlines      |
| sm    | 8px   | Stat grid row gap, panel internal gaps      |
| md    | 16px  | Panel padding (all four sides)              |
| lg    | 24px  | Section vertical spacing                    |
| xl    | 32px  | Layout column gaps                          |
| 2xl   | 48px  | Major section breaks (not used in Phase 12) |
| 3xl   | 64px  | Page-level spacing (not used in Phase 12)   |

Exceptions:

- PIECE_RADIUS = 12px (SVG coordinate unit, not a CSS spacing token — locked by existing code)
- Mini token diameter = 18px (SVG, for PlayerStatsPanel header badge — D-08)
- Stat grid row gap = 3px (existing CSS, out of 4px scale — intentional density; do not change)
- `strokeWidth` values are SVG paint attributes, not spacing: 1.5px (base piece border), 2px (ring strokes), 2.5px (activated ring + spent X)

### NEW: Selection Ring Colors (Phase 12 — D-04, UX-05)

Replaces current gold `#f5c518` selected ring and boolean `isHeaderContestant` green ring.

| `selectionState` | Ring color              | Ring stroke | Ring radius               | Stroke width | Cursor    |
| ---------------- | ----------------------- | ----------- | ------------------------- | ------------ | --------- |
| `none`           | — (no ring)             | —           | —                         | —            | `default` |
| `selectable`     | `#3b82f6` (bright blue) | —           | `PIECE_RADIUS + 2` = 14px | 2px          | `pointer` |
| `active`         | `#22c55e` (green)       | —           | `PIECE_RADIUS + 4` = 16px | 2.5px        | `pointer` |
| `activated`      | `#f97316` (orange)      | —           | `PIECE_RADIUS + 3` = 15px | 2px          | `default` |

Note: `activated` also renders the red X overlay (`stroke="#ef4444"`, strokeWidth 2.5, strokeLinecap round)
at `±PIECE_RADIUS * 0.7` from center — identical geometry to current `isSpent` path. Both ring and X
render together; they are a single `selectionState === 'activated'` branch, not two separate conditions.

Accent reserved for:

- `selectable` ring: piece the local player may click to select this turn
- `active` ring: the currently selected piece (or header contestant during HEADER phase)
- `activated` ring + X: piece that has already completed its activation this movement phase
- `#f5c518` (gold): stat panel stat value highlights only — NOT used for any SVG ring in Phase 12+

### NEW: Hex Highlight Tint Colors (Phase 12 — D-10/D-12, UX-06)

Replaces current `highlightColor?: string` free-form prop with named semantic types.
All tints are semi-transparent RGBA fills rendered as an overlay polygon on top of the grass base.
Base hover opacity +0.15 on mouse enter (consistent with existing HexCell hover behavior).

| `highlightType` | Fill color            | Fill opacity (rest/hover) | Stroke color | Stroke width      | Cursor    |
| --------------- | --------------------- | ------------------------- | ------------ | ----------------- | --------- |
| `safe`          | `rgba(245,197,24,1)`  | 0.50 / 0.65               | `#d4a017`    | 1.5px / 2px hover | `pointer` |
| `risk`          | `rgba(255,165,0,1)`   | 0.40 / 0.55               | `#cc7700`    | 1.5px / 2px hover | `pointer` |
| `goal`          | `rgba(220,50,50,1)`   | 0.50 / 0.65               | `#cc2222`    | 1.5px / 2px hover | `pointer` |
| `kickoff`       | `rgba(59,130,246,1)`  | 0.40 / 0.55               | `#2563eb`    | 1.5px / 2px hover | `pointer` |
| `shot-path`     | `rgba(255,255,255,1)` | 0.35 / 0.50               | `#cccccc`    | 1.5px / 2px hover | `pointer` |

Priority order when multiple types would apply to a single hex (D-12):
`risk` > `goal` > `shot-path` > `kickoff` > `safe`

HexCell receives exactly one `highlightType` value (or `undefined` for no highlight). The priority
resolution lives entirely in HexGrid before passing props to HexCell. HexCell owns the color lookup
table only.

Difficult-angle dot: `fill="#ffffff"` `fillOpacity={0.3}` radius 3px — orthogonal to tints, unchanged.

## SVG Pattern Spec (Stripe Patterns — D-01/D-02/D-03)

Defined once in `HexGrid`'s `<defs>` block and referenced via `fill="url(#home-stripe)"` /
`fill="url(#away-stripe)"` on the piece base `<circle>`. Separately self-contained in
`PlayerStatsPanel`'s inline `<svg>` per D-09.

### Home stripe (`#home-stripe`)

Single vertical black stripe centered on the token.

| Property                 | Value                      | Rationale                                     |
| ------------------------ | -------------------------- | --------------------------------------------- |
| Pattern width            | 24px (= PIECE_RADIUS \* 2) | Matches token diameter                        |
| Pattern height           | 24px                       | Square tile                                   |
| patternUnits             | `userSpaceOnUse`           | Positioned in SVG coordinate space            |
| Pattern offset x         | `cx - PIECE_RADIUS`        | Aligns stripe center with token center        |
| Stripe rect x            | 10px (of 24px tile)        | Centered — 1px either side of midpoint        |
| Stripe rect width        | 4px                        | ~17% of diameter; visible but not dominating  |
| Stripe rect fill         | `#000000`                  | Black stripe on blue base                     |
| Stripe rect fill-opacity | 0.55                       | Softer than solid black; legible on `#1a56b0` |

### Away stripe (`#away-stripe`)

Two horizontal dark bands, evenly spaced.

| Property           | Value               | Rationale                                                     |
| ------------------ | ------------------- | ------------------------------------------------------------- |
| Pattern width      | 24px                | Matches token diameter                                        |
| Pattern height     | 24px                | Square tile                                                   |
| patternUnits       | `userSpaceOnUse`    | Positioned in SVG coordinate space                            |
| Pattern offset y   | `cy - PIECE_RADIUS` | Aligns bands with token                                       |
| Band 1 rect y      | 6px (of 24px tile)  | Upper third — first horizontal band                           |
| Band 1 rect height | 4px                 | ~17% of diameter                                              |
| Band 2 rect y      | 14px (of 24px tile) | Lower third — second horizontal band                          |
| Band 2 rect height | 4px                 | Equal to band 1                                               |
| Band fill          | `#7f0000`           | Dark maroon — distinct from red token base `#c0392b`          |
| Band fill-opacity  | 0.65                | Legible against `#c0392b`; matches physical board dark stripe |

Pattern IDs must be unique within each SVG document scope:

- HexGrid SVG root: `id="home-stripe"` and `id="away-stripe"`
- PlayerStatsPanel inline SVG: use same IDs — safe because each `<svg>` is an independent document fragment

## Interaction Contract

### Piece click behavior (unchanged semantics, new prop API)

| `selectionState` | Click result                                  |
| ---------------- | --------------------------------------------- |
| `selectable`     | `onClick()` fires → `selectPiece` in Zustand  |
| `active`         | `onClick()` fires (deselect or re-select)     |
| `activated`      | `onInspect()` fires only (cannot re-activate) |
| `none`           | `onInspect()` fires only                      |

Cursor `pointer` when `selectionState !== 'none'` and `selectionState !== 'activated'`.
Cursor `default` when `none` or `activated`.

### Hex click behavior (unchanged semantics, new prop API)

| `highlightType`   | Click result                     |
| ----------------- | -------------------------------- |
| any defined value | `onClick()` fires                |
| `undefined`       | no click handler; cursor default |

### Header contestant phase mapping

During `phase === 'HEADER'` before `bothConfirmed`:

- All pieces eligible for header contest → `selectionState: 'active'` (green ring)
- This replaces `isHeaderContestant` prop entirely (D-07)

## Accessibility Notes

- All SVG rings and tint overlays use `pointerEvents="none"` — they do not intercept click events
- `<polygon>` hex cells retain `aria-hidden="true"` (existing pattern; unchanged)
- Color is not the only differentiator for selection state: `activated` also shows a red X shape
- Stripe patterns provide visual team differentiation beyond color (VIS-01 requirement)
- Difficult-angle dot (existing) remains orthogonal: `fill="#ffffff" fillOpacity={0.3}`
