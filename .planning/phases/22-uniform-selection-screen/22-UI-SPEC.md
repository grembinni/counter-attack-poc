## Layout Contract

### Screen structure

Single `UniformSelectionScreen.tsx` component (new file — D-01 Claude discretion). CSS module: `UniformSelectionScreen.module.css`.

```
.screen   — full-viewport flex column, align-items center, background #1a1a2e, gap 16px, padding 24px
  .heading              — "Home: choose your team + style" / "Away: choose your team + style"
  [.statusLine]         — "Waiting for home player to choose…" (away, while home hasn't confirmed)
  [.opponentBanner]     — "Opponent confirmed" banner (away only, after home confirms) — see below
  [.speedSelector]      — Carried through from Phase 21 / TeamSelectionScreen (home player only)
  .sectionLabel         — "Choose your team:"
  .teamGrid             — 2 × 6 flat grid (preferred), fallback 3 × 4 if 2 × 6 overflows viewport
  .sectionLabel         — "Choose your style:"
  .styleGrid            — 6 × 3 flat grid (all 18 styles)
  .confirmButton        — single "Confirm selection" CTA, disabled until both team AND style selected
```

### Team grid (D-02)

- Layout: `display: grid; grid-template-columns: repeat(6, 1fr); gap: 16px; max-width: 800px;`
- Fallback at narrow viewports: `@media (max-width: 760px) { grid-template-columns: repeat(3, 1fr); max-width: 420px; }`
- Card size: min-width 100px, min-height 120px (reduced from 180px since no tab header overhead)
- Card content: badge `<img>` at 80×80, optional team name label below at 13px/700
- Team ordering (D-02 / CONTEXT.md specifics): MLS teams first (city, crew, la, miami, nashville, seattle), then International (canada, england, france, mexico, spain, us) — all 12 in one flat sequence, no tab separator
- Card states: `.teamCard` (default), `.teamCardSelected` (selected by this player — border glow in homePrime), `.teamCardStruckOut` (away player cannot select — opacity 0.4, cursor not-allowed)

### Style tile grid (D-03, D-07, D-10)

- Layout: `display: grid; grid-template-columns: repeat(6, 1fr); gap: 8px; max-width: 560px;`
- Tile size: 80px × 80px (D-10)
- Tile content: inline SVG, 80×80 viewport, piece centred at cx=40 cy=40 R=30
- Jersey number on tile: 1-based index in ALL_STYLE_IDS ordered list (style at index 0 → number "1", etc.)
- pieceId for SVG uniqueness: `'style-{n}'` where n is 1-based index (e.g. `pieceId: 'style-1'`)
- Tile states:
  - `.styleTile` — default card, border: 1px solid #0f3460, background: #16213e, border-radius 4px
  - `.styleTileSelected` — border: 3px solid {team homePrime or #e0e0e0}, box-shadow: 0 0 0 2px {same color}, background: #16213e
  - `.styleTile:hover:not(:disabled)` — box-shadow: 0 0 0 1px #a0a0a0
- Before team selected: palette `{ homePrime: '#555', homeAlt: '#ccc', homeFont: '#fff', awayPrime: '#555', awayAlt: '#ccc', awayFont: '#fff', uiColor: '#555' }` — neutral grey scheme (D-05, CONTEXT.md specifics)
- After team selected: full team palette from `COLOR_SCHEME_REGISTRY[TEAM_CONFIGS[teamId].colorSchemeId]` or equivalent palette source
- All 18 style tiles are always visible regardless of team selection state (D-03)
- The team's `defaultUniformStyle` tile is pre-highlighted (`.styleTileSelected`) on screen mount (D-09 / UNIFORM-03)

### "Opponent confirmed" banner (D-11)

Visible to away player only, after home emits `UNIFORM_HOME_CONFIRMED`.

```
.opponentBanner
  — max-width 560px, width 100%
  — background: #16213e
  — border-left: 3px solid {home homePrime}
  — border-radius: 4px
  — padding: 8px 16px
  — display: flex; align-items: center; gap: 12px

  .bannerPiece   — 48×48 inline SVG, home piece rendered with home palette + home confirmed style
  .bannerText    — "Opponent confirmed" at 13px/700 #e0e0e0
```

Banner does NOT show home's team name — only the rendered piece. Away player infers the team from the colors.

### Confirm button (D-06)

- Label: "Confirm selection"
- Position: below style grid, centered
- Disabled state: when `selectedTeam === null` OR `selectedStyle === null`, button is `disabled` with opacity 0.5
- Enabled state once both are selected, background #0f3460
- After confirming: button hidden or replaced by "Waiting for opponent…" status line
- Width: same as grid max-width (auto / max-content, min-width 160px)

## Interaction Contract

### Turn sequencing (D-04, D-06)

1. Both players land on the screen simultaneously when `UNIFORM_SELECTION_START` fires.
2. Home player: sees active team grid, active style grid, enabled Confirm (once both selected). Speed selector visible.
3. Away player: sees same screen layout. Home's team card is struck-out from the start (server sent `homePickedTeam` in room state, or App.tsx holds it from `TEAM_HOME_PICKED`). Away may freely change their team and style until Confirm.
4. After home confirms: server broadcasts `UNIFORM_HOME_CONFIRMED { teamId, uniformStyle }`. Away's screen shows the banner. Away's Confirm button is now unblocked by any home-lock (away was always able to confirm independently — the sequencing is just informational).
5. After away confirms: server builds game state and broadcasts `GAME_STATE`. Both screens transition to `GAME_BOARD`.

### Selection interaction

- Clicking a team card that is not struck-out: sets `selectedTeam`, re-renders all 18 style tiles in new palette, keeps `selectedStyle` as the team's `defaultUniformStyle` (or previously selected style if already chosen)
- Clicking a style tile: sets `selectedStyle`; tile border highlight moves to clicked tile
- Clicking Confirm: disabled if either selection is null; fires `UNIFORM_CONFIRM { teamId, uniformStyle }` socket event; button replaced by "Waiting for opponent…"

### States for the Confirm button

| State     | Trigger                      | Visual                                                     |
| --------- | ---------------------------- | ---------------------------------------------------------- |
| Disabled  | No team OR no style selected | opacity 0.5, cursor not-allowed                            |
| Enabled   | Both team and style selected | background #0f3460, cursor pointer                         |
| Submitted | Player clicked Confirm       | Button hidden; ".statusLine" shows "Waiting for opponent…" |

## SVG Tile Rendering Contract

Each style tile is a standalone `<svg width={80} height={80}>` element:

```tsx
// Pseudo-code for tile SVG assembly
const result = UNIFORM_STYLES[styleId]({
  cx: 40,
  cy: 40,
  R: 30,
  palette: selectedTeam ? teamPalette : NEUTRAL_PALETTE,
  isGK: false,
  pieceId: `style-${index + 1}`, // 1-based, globally unique within the screen
});

<svg width={80} height={80} xmlns="http://www.w3.org/2000/svg">
  <defs>{result.patternDef}</defs>
  <circle cx={40} cy={40} r={30} fill={result.fill} />
  {result.overlay}
  {/* Jersey number centred on piece */}
  <text
    x={40}
    y={44}
    textAnchor="middle"
    fontSize={14}
    fontWeight={700}
    fill={selectedTeam ? palette.homeFont : '#fff'}
    pointerEvents="none"
  >
    {index + 1}
  </text>
</svg>;
```

Neutral palette constant (D-05, CONTEXT.md specifics):

```ts
const NEUTRAL_PALETTE: TeamPalette = {
  homePrime: '#555',
  homeAlt: '#ccc',
  homeFont: '#fff',
  awayPrime: '#555',
  awayAlt: '#ccc',
  awayFont: '#fff',
  uiColor: '#555',
};
```

## Accessibility Contract

- All team card `<button>` elements: `aria-pressed={teamId === selectedTeam}`, `aria-label="{teamName} — {league}"`, `disabled` when struck-out
- All style tile `<button>` elements: `aria-pressed={styleId === selectedStyle}`, `aria-label="{styleName}"` (from `UNIFORM_STYLE_META[styleId].name`)
- Confirm button: `aria-disabled` mirrors `disabled` attribute; `aria-label="Confirm team and style selection"`
- Opponent banner: `role="status"` so screen readers announce it when it appears
- Focus management: no custom focus trapping — natural tab order is sufficient (pre-game selection screen, desktop only per REQUIREMENTS.md out-of-scope)
