| ------------------------- | ------------------------------------------------------- |
| User input → room code    | LobbyScreen Join Room input: untrusted string from user |
| ActionEvent content → DOM | ActionEvent union values rendered as text in ActionLog  |

## STRIDE Threat Register

| Threat ID | Category               | Component                         | Disposition | Mitigation Plan                                                                                                                                                           |
| --------- | ---------------------- | --------------------------------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| T-06-06   | Tampering              | ActionLog — ActionEvent rendering | mitigate    | JSX string interpolation only — formatEvent(event) returns a plain string; JSX renders it as text node; React never calls innerHTML; dangerouslySetInnerHTML is forbidden |
| T-06-07   | Tampering              | LobbyScreen room code input       | mitigate    | Input onChange: value.toUpperCase().slice(0, 6) — no injection surface, max 6 chars; no server call in Phase 6                                                            |
| T-06-08   | Information Disclosure | navigator.clipboard.writeText     | accept      | Only reveals the room code (which the user just generated); HTTPS required in production (Phase 9 ARCH-06 handles this)                                                   |
| T-06-SC   | Tampering              | npm/pip/cargo installs            | mitigate    | No new packages in Wave 3; all packages verified in 06-RESEARCH.md audit                                                                                                  |
