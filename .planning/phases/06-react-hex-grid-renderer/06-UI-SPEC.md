## Hex Grid Visual Spec

_Source: CONTEXT.md D-01, D-02, D-03, D-04, D-05_

### Geometry

| Property             | Value                                                                                                                           |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| Orientation          | Flat-top                                                                                                                        |
| Grid dimensions      | 37 columns (q ∈ [0, 36]) × 26 rows (r ∈ [0, 25]) = 962 hexes                                                                    |
| Hex size (hexSize)   | 20px — the circumradius; defines polygon vertex distance from center                                                            |
| SVG polygon points   | Flat-top vertices at angles 0°, 60°, 120°, 180°, 240°, 300°                                                                     |
| axialToPixel formula | `cx = hexSize * (3/2 * q)`, `cy = hexSize * (√3/2 * q + √3 * r)`                                                                |
| SVG viewBox          | Computed from max cx/cy of q=36, r=25: `0 0 {maxCx + hexSize} {maxCy + hexSize}`                                                |
| SVG width            | 100% of pitch container (fills ~80% viewport width at 1280px)                                                                   |
| SVG height           | Proportional to viewBox aspect ratio — do not set fixed height                                                                  |
| Half-hex clipping    | Apply `clipPath` rect from y=0 to SVG container height — top/bottom row hexes are visually half-clipped matching physical board |
| Stroke width         | 0.5px on all hex borders                                                                                                        |

**hexSize = 20px reasoning:** At 1280px viewport with 80% for pitch (1024px), the 37-column flat-top grid needs approximately `37 * 20 * 1.5 ≈ 1110px` of SVG coordinate space. With `width: 100%` and correct viewBox, the SVG scales to fit 1024px container cleanly. Adjust at implementation if visual inspection shows too small/large.

### Hex Fill States

| State                     | Fill                                       | Stroke          | Notes                                                                |
| ------------------------- | ------------------------------------------ | --------------- | -------------------------------------------------------------------- |
| Normal — light            | `#4a7c3f`                                  | `#2d5227` 0.5px | `(q + r) % 2 === 0`                                                  |
| Normal — dark             | `#3d6b34`                                  | `#2d5227` 0.5px | `(q + r) % 2 === 1`                                                  |
| Valid move destination    | `#f5c518` at 0.55 opacity over normal fill | `#d4a017` 1.5px | Rendered as a second `<polygon>` overlay, not replacing the base hex |
| Goal hex                  | `#1a1a1a`                                  | `#2d5227` 0.5px | q=0 r∈[9,15]; q=36 r∈[9,15]                                          |
| Hovered (non-highlighted) | No change                                  | No change       | No hover feedback on non-interactive hexes                           |
| Hovered (highlighted)     | `#f5c518` at 0.75 opacity                  | `#d4a017` 2px   | Brighter on hover to invite click                                    |

### Hex Overlay Elements (rendered as SVG children over hex polygon)

| Overlay                    | Shape                          | Size                | Color                    | Condition                                         |
| -------------------------- | ------------------------------ | ------------------- | ------------------------ | ------------------------------------------------- |
| Difficult-angle dot        | `<circle>`                     | r=3px at hex center | `#ffffff` at 30% opacity | `isDifficultAngle(hex) === true`                  |
| Penalty area dashed border | `<polyline>` on boundary edges | 1px dashed          | `#c8c8c8`                | Edge between penalty area hex and non-penalty hex |
| Centre circle dashed       | `<circle>` or `<polygon>` ring | 1px dashed          | `#c8c8c8`                | Visual ring at hexDistance=3 from kickoff hex     |

## Interaction Contract

_Source: REQUIREMENTS.md PITCH-04, UX-02, CONTEXT.md D-07, D-09_

### Click Handlers

| Target                                  | Condition                                          | Effect                                                                                                            |
| --------------------------------------- | -------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| Piece circle (own team, MOVEMENT phase) | Piece belongs to `activeTeam`, phase is `MOVEMENT` | `selectPiece(id)` — computes valid moves via `validateMove()`, stores in `validMoveHexes`, sets `selectedPieceId` |
| Piece circle (already selected)         | `selectedPieceId === id`                           | Deselect — clear `selectedPieceId` and `validMoveHexes`                                                           |
| Highlighted hex                         | Hex is in `validMoveHexes`                         | `movePiece(targetHex)` — updates mock GameState locally (Phase 6); emits socket in Phase 7                        |
| Any non-highlighted hex                 | Hex not in `validMoveHexes`                        | No effect — no visual feedback                                                                                    |
| Opponent piece                          | Always                                             | No effect                                                                                                         |
| Own piece (not MOVEMENT phase)          | Phase is not MOVEMENT                              | No effect                                                                                                         |

### Cursor Rules

| Target                      | Cursor    |
| --------------------------- | --------- |
| Own piece in MOVEMENT phase | `pointer` |
| Highlighted valid-move hex  | `pointer` |
| All other SVG elements      | `default` |

### Valid Move Highlighting

1. User clicks an own-team piece during MOVEMENT phase
2. Client calls `validateMove(gameState, pieceId, candidateHex)` for each hex in `hexesInRange(piece.position, piece.pace)` to build `validMoveHexes`
3. Each hex in `validMoveHexes` renders the highlight overlay polygon
4. Clicking a highlighted hex calls `movePiece(targetHex)` which mutates mock GameState via Zustand
5. After move: `selectedPieceId = null`, `validMoveHexes = []`, piece position updated in store

**No animation.** Piece teleports to destination hex. Static state transition only (per REQUIREMENTS.md out-of-scope).
