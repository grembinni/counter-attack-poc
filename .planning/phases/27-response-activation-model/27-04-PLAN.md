<objective>
Layer D-12's shot-path eligibility filter onto the existing `SNAPSHOT_DEFLECT` phase and
change D-03's resolution timing: today the deflect dice roll fires when the defender clicks
"End Turn"; per D-03 it must fire automatically the instant the defender's single
positioning move resolves, with no confirm button. Per D-20, the existing 2-hex pace cap is
unchanged — D-12's "distance 3" is purely an eligibility/highlight radius layered on top.

Purpose: `SNAPSHOT_DEFLECT` already has the exact single-selection movement primitive this
phase wants everywhere else (`validateResponseMoveStep`/`computeResponseMoveValidHexes`) —
this plan is the smallest possible proof that the eligibility-filter + auto-fire pattern
works before Plan 27-05 builds the much larger, genuinely-new HEADER positioning step on the
same foundations.
Output: shot-path-gated, auto-resolving SNAPSHOT_DEFLECT.
</objective>
