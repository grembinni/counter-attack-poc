- 14px used for scoreboard side-cell horizontal padding — inherited; preserve
- Touch target minimum for team card buttons: 120px × 180px (card size); no smaller

Source: all inherited from existing CSS Modules across prior phases

## Interaction Contract

### Team Selection Screen — turn sequence states

| State                               | Home player view                                                           | Away player view                                        |
| ----------------------------------- | -------------------------------------------------------------------------- | ------------------------------------------------------- |
| `homePickedTeam === null` (initial) | 4 cards active, clickable                                                  | 4 cards disabled (opacity 0.4)                          |
| Card clicked by home (pre-confirm)  | Emit `team:pick`; client disables card immediately                         | No change                                               |
| After `team:home-picked` received   | Home's card shows struck-out; remaining 3 still visible at reduced opacity | 3 remaining cards become active; home's card struck-out |
| After away picks                    | Both screens transition to GAME_BOARD                                      | Both screens transition to GAME_BOARD                   |

The transition to GAME_BOARD is driven by receiving the initial `game:state` socket event (existing pattern — no new transition needed beyond wiring `team:selection-start` → `setScreen('TEAM_SELECTION')`).

### Team card click handling

- Active card click: emit `team:pick { teamId }` immediately; disable the clicked card optimistically in local state. Do NOT wait for server confirmation before disabling — prevents double-click.
- If server rejects (e.g. wrong player slot): server emits no `team:home-picked`; client stays in selection state. No error copy needed for this phase (out of scope per DEFERRED).
- Struck-out card: `pointer-events: none` + `disabled` attribute — not clickable by either player.

### Screen routing in App.tsx

Add branch before the existing GAME_BOARD check:

```
screen === 'TEAM_SELECTION' → <TeamSelectionScreen ... />
screen === 'GAME_BOARD' || screen === 'REPLAY' → <GameBoard />
else → <LobbyScreen />
```
