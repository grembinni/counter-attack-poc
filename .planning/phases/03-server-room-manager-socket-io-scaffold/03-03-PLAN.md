<objective>
Wire the Express + Socket.io server (Pattern 1 in RESEARCH.md), implement the room event handlers (ROOM_CREATE, ROOM_JOIN, disconnect with 90-second grace timer and warning broadcast, reconnect path with timer cancel and state re-emit), and prove the whole stack works with a Socket.io-client integration test suite. This plan delivers every Phase 3 success criterion that requires the live socket layer: CONN-01 (room code returned to creator), CONN-02 (slot-2 joiner), CONN-03 (game:state auto-broadcast when both joined), CONN-04 (NOT_FOUND + NOT_WAITING error events), ARCH-01 (server-authoritative — client never assigns its own slot), ARCH-04 (full snapshot broadcast via broadcastState), and SC-3 (reconnect within 90s cancels timer + receives current state), SC-5 (/health returns 200).

Purpose: Convert the Plan 02 pure-function pieces into a live, testable Socket.io server. Plan 02 left the room store and middleware as pure modules; this plan ties them to actual sockets via `io.use()` and `io.on('connection')` and proves the wire-level behaviour with `socket.io-client` tests that spin up the server on port 0 and connect typed clients to it.
