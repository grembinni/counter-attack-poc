# Phase 17.1 Plan 09: ZoI Tackle/Steal Exclusion Symmetry Fix Summary

**Fixed asymmetric D-02 ZoI exclusion: moveValidator's tackle branch now preserves move validity for spent tacklers (mirroring the steal branch), and HexGrid's steal-risk tint now clears after a failed steal attempt by filtering on stealAttemptedByIds.**

## Performance

- **Duration:** 5 min
- **Started:** 2026-06-19T15:16:31Z
- **Completed:** 2026-06-19T15:21:23Z
- **Tasks:** 2 completed
- **Files modified:** 4 (1 created, 3 modified)

## Accomplishments

- `moveValidator.ts`'s tackle branch no longer rejects the move outright (`{ ok: false, reason:
'TACKLE_ALREADY_ATTEMPTED' }`) for a defender who already attempted a tackle this sequence —
  it now falls through to plain `{ ok: true }` (move stays valid, just no `TACKLE_ATTEMPT`
  effect), exactly mirroring the existing correct steal-branch pattern in the same file.
- Removed the now-unreachable `TACKLE_ALREADY_ATTEMPTED` reason from the `MoveResult` reject
  union; confirmed via repo-wide grep that no other code (engine, handlers, tests) referenced it.
- `HexGrid.tsx`'s `zoiRiskSet` (steal-risk/orange tint) now filters `getZoIDefenders` results
  by `state.stealAttemptedByIds` before counting, so the tint correctly clears for a defender
  once they've already faced a steal attempt — previously this computation never referenced
  either exclusion array at all (confirmed by the prior debug session's grep).
- Added a new `stealAttemptedByIds` Zustand selector subscription in `HexGrid.tsx`, placed near
  the other per-slice subscriptions (Pitfall 6 pattern).
- New test coverage: 3 shared tests (excluded tackler → no effect, non-excluded tackler →
  regression guard, dual-flagged tackle+steal piece → no effect at all) and 3 client tests
  (excluded-only defender suppresses tint, non-excluded defender keeps tint, mixed
  excluded+non-excluded defenders keep tint).

## Decisions Made

- Mirrored the steal branch's exact pattern in the tackle branch rather than introducing a new
  abstraction — both branches now follow "guard the effect return with a negated includes()
  check, let the function's final plain `{ ok: true }` be the natural fallthrough."
- Verified via grep that `TACKLE_ALREADY_ATTEMPTED` had zero other references before removing it
  from the type union, per the plan's explicit instruction to confirm rather than trust the prior

- Created a new `HexGrid.test.tsx` file since none existed previously, following the file's
