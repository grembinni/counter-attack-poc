## Decisions Made

- **FTP_MOVE event type added** — mirroring HP_MOVE; records piece repositioning moves within FIRST_TIME_PASS_MOVE. The plan sketch only mentioned FTP_REPOSITION (slot boundary) but HP_MOVE is a separate event type in the HP pattern; added FTP_MOVE for consistency.
- **D-06 guard placement** — inserted after HALF_TIME/FULL_TIME check so clock math (newActionCount, newAddedTime) is already computed before the GK check; this avoids duplicating clock update logic in the GK_RESTART return path.
- **isInRegion called with string key** — `isInRegion(pos, 'homePenaltyArea')` not `PITCH_REGIONS.homePenaltyArea`; the function signature takes a `keyof` string literal, not the Set itself.
- **BUG-05 and RULE-03 test updates** — D-07 intentionally changes save-spill from LOOSE_BALL to GK_RESTART; pre-existing tests that asserted LOOSE_BALL were updated to assert GK_RESTART (correct behavior per spec).
