<objective>
Fix the diagnosed root cause of UAT Test 7 (gap closure for Phase 17.1): `HexGrid.tsx`'s
`isShootingModeGoalHex` computation has two branches joined by `||` — the `SNAPSHOT_TARGET` branch
correctly gates on `hexDistance(snapCarrier.position, hex) <= 6`, but the regular-shot
`shootingMode ||` branch has NO distance filter at all, so it unconditionally highlights all 7
goal-line hexes whenever shooting mode is active, regardless of shooter position. The server's
`applyDeclareShot` (D-09, gameEngine.ts) already correctly rejects out-of-range targets — this is a
pure client-side highlight-accuracy bug; no invalid state is reachable via direct click.

Root cause and fix direction are already fully diagnosed in
`.planning/debug/shot-range-gate-no-filter.md` — this plan applies that fix directly, it does not
re-investigate.

Purpose: Make the client-side regular-shot highlight match the server's D-09 11-hex range gate, so
players only see selectable targets they can actually hit.
Output: Corrected isShootingModeGoalHex regular-shot branch with matching distance filter.
</objective>
