<objective>
Fix the diagnosed root cause of UAT Test 3 (gap closure for Phase 17.1): the FIRST_TIME_PASS_MOVE
transition in `applyRoll()`'s `'PASS'` case is unreachable whenever the pass target hex is occupied,
because a pre-existing occupant-check early-return (lines ~1223-1248) runs BEFORE the D-03
FIRST_TIME_PASS_MOVE check (line ~1312). Since a first-time pass is virtually always aimed at a
visible teammate's hex (occupied), this means the repositioning prompt never fires in real play —
exactly matching the user report "there was no prompt for either team to move after first-time pass."

Root cause and fix direction are already fully diagnosed in
`.planning/debug/ftp-no-reposition-prompt.md` — this plan applies that fix directly, it does not
re-investigate.

Purpose: Restore the D-03 FIRST_TIME_PASS_MOVE repositioning flow (17.1-CONTEXT.md) for the
realistic occupied-target case, which is the only case that matters in actual gameplay.
Output: Reordered `applyRoll` PASS branch; corrected regression test; new end-to-end test.
</objective>
