<objective>
Plumb the "Out-of-Bounds / Restarts" game-creation toggle end to end: host checkbox → `ROOM_SETTINGS_CONFIRM` → `Room.outOfBoundsEnabled` → `buildInitialGameState` → `GameState.outOfBoundsEnabled` (OOB-05, GOALKICK-06).

Purpose: OOB-05 requires that when the toggle is off, the ball keeps clamping to the pitch boundary exactly as it does today and none of the new restart flows are reachable. That guarantee is only enforceable if the flag reaches the engine before Plan 37-04 adds the classification hook. GOALKICK-06 requires this be a toggle independent of Fouls/Booking/Injury (which land in Phase 39) — so it is its own boolean, not part of a shared bitmask or grouped object.

Output: toggle wired through server settings and client settings screen; no gameplay behaviour changes yet (nothing reads the flag until Plan 37-04).
</objective>
