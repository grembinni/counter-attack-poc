<objective>
Migrate the fourth and final surface — the bench card — and in doing so give it card/injury
iconography for the very first time. `BenchCarousel`/`DraftCardBody` today shows only a `RED CARD` or
`OUT` availability text badge and has no disciplinary or fitness display at all.

Purpose: ROADMAP Phase 41 Success Criterion 2 is unambiguous — "a bench player who has been booked
**or injured** now shows that status on the bench, which it never did before". Plan 41-02 put the
data on `BenchEntry`; this plan renders it. Phase 42's bench red-card marker consumes this component,
so partial implementation is not an option (`41-CONTEXT.md` Integration Points).
Output: two new optional props on `DraftCardBody`, one new prop on `BenchCarousel`, a derivation in
`LineupAssignmentScreen`'s mid-match branch, and the bench's first glyph test coverage.
</objective>
