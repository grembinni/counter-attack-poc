<objective>
Fix the high-pass header sequencing bugs RULE-01 and RULE-02 on the server. RULE-01: gate the
header contestant selection UI behind an accuracy-roll acknowledgment flag so the roll result is
shown before contestants are chosen. RULE-02: fire the heading duel automatically when both teams
confirm contestants, record the winner, then let only the winning team select the target hex
(validated against the winning contestant's position).

Purpose: The v1.0 flow skipped showing the accuracy roll and let the attacker pick the target hex
even when a defender won the header. This corrects the accuracy-check -> contestant-duel ->
target-selection sequence.
Output: Two new GameState fields, one new client event, a new pure engine function, three handler
changes, and server unit/handler tests proving the new sequence.
</objective>
