| localStorage → socket auth | Session token read from localStorage is sent in the handshake auth callback                       |

## STRIDE Threat Register

| Threat ID | Category  | Component                                             | Disposition | Mitigation Plan                                                                                                                       |

| T-07-02   | Elevation | localStorage `ca_session_token` read in auth callback | accept      | Token has 90s grace value only; server findPlayerByToken is point-in-time; deleted rooms invalidate tokens (RESEARCH Security Domain) |
