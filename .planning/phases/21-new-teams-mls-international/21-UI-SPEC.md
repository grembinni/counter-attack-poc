## Interaction Contract

### Tab Switching

- Clicking "MLS" tab sets `activeLeague = 'mls'`; grid re-renders with `MLS_TEAMS` (6 teams)
- Clicking "International" tab sets `activeLeague = 'international'`; grid re-renders with `INTL_TEAMS` (6 teams)
- Tab switch is instant (no animation required); CSS transition on `border-bottom-color` and `color` at 0.15s ease
- Default on mount: `activeLeague = 'mls'` (MLS tab active, per LEAGUE-01)

### Auto-Switch (LEAGUE-02)

- When `homePickedTeam` changes and the current player is the away player (`!iAmActive`), auto-switch to the tab containing the just-picked team
- Guard: only fires when `homePickedTeam !== null && !iAmActive`
- Implementation: `useEffect([homePickedTeam, iAmActive])` — do NOT fire during render
- **Does not fire for the home player** — home player's tab stays wherever they left it after picking

### Struck-Out Card

- A team card is struck out if `teamId === homePickedTeam`, regardless of which tab is active
- Struck-out state: `opacity: 0.4`, `cursor: not-allowed`, team name has `text-decoration: line-through`
- Struck-out state is visible on the inactive tab when user switches back — the `homePickedTeam` check is independent of `activeLeague`

### Card Click

- Active (not struck out, not disabled) cards: clicking emits the team pick event (existing behavior, unchanged)
- Disabled cards (away player's turn — `!iAmActive` and the card is home's card): `disabled` attribute, `opacity: 0.4`, `cursor: not-allowed`
- No hover effect on disabled or struck-out cards (`:hover:not(:disabled)` guard already in existing CSS)

### Focus / Accessibility

- Tab buttons are `<button>` elements (not `<div>`) — keyboard-focusable by default
- Active tab button has `aria-selected="true"`; inactive has `aria-selected="false"`
- Tab container has `role="tablist"`; each tab button has `role="tab"`
- Team card grid has `role="tabpanel"` when tabs are present

## States to Handle

| State                                | Trigger                              | Visual                                                                                        |
| ------------------------------------ | ------------------------------------ | --------------------------------------------------------------------------------------------- |
| MLS tab active                       | Default on mount                     | "MLS" tab underlined in `#e0e0e0`; 6 MLS team cards visible                                   |
| International tab active             | User clicks "International"          | "International" tab underlined; 6 international cards visible                                 |
| Home player has picked (home's view) | `homePickedTeam` set after emit      | Home sees their own card in `.cardStruckOut`; away tab auto-switches                          |
| Away player sees pick (away's view)  | `homePickedTeam` received via socket | Away sees struck-out card on whichever tab home picked from; tab auto-switches to that league |
| Away player picks (away's view)      | Away emits pick                      | Screen advances (existing behavior, unchanged)                                                |
| Waiting (home picked, away hasn't)   | `iAmActive === false`                | Status line shown; away picks from either tab                                                 |
