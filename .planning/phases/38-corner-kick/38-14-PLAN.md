<objective>
Replace the Phase 17.1 D-07 placeholder that treats a spilled goalkeeper save as a clean catch
with the real mechanic: a spill produces a genuine Loose Ball, and a scatter that crosses the
keeper's own byline is awarded as a Corner Kick to the attacking team.

Purpose: gap-closure item 2 from `38-09-SUMMARY.md`. `shotValidator.ts`'s `validateHandlingCheck`
already returns `triggerLooseBall: true` on a failed handling check, but `gameEngine.ts`'s SAVE
branch (lines 2794-2816) discards it and returns the identical `GK_RESTART` state as a clean
catch, marked by the comment "pending out-of-bounds rules — spill treated as clean catch for now".
The out-of-bounds and corner-kick machinery that TODO was waiting for now exists (Phase 37 and
Phase 38). This is a second, currently-missing route into a corner kick; OOB-03's byline-exit
route is unaffected and already verified. The user explicitly directed this into Phase 38's
gap-closure run rather than a separate phase.

Output: the spill branch transitioning to `LOOSE_BALL`, mirroring the existing SHOT duel-tie
branch, so the already-built `LOOSE_BALL` scatter walk routes a byline exit through
`triggerOutOfBoundsRestart` and `classifyOutOfBounds` into `CORNER_KICK_GK_SETUP_ATTACKING`.
</objective>
