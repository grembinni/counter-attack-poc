## Scope note — Penalty Kick is not omittable, it is not yet buildable

`38-15-SUMMARY.md` defect 4 names five restarts. Four have a `GamePhase` entry point today:
`THROW_IN_SETUP`, `GOAL_KICK_SETUP_GK`, `CORNER_KICK_CLEAR_OUT`, `FREE_KICK_SETUP`. Penalty Kick
has none — `grep -rn "PENALTY" packages/shared/src` returns only the `NOT_IN_PENALTY_AREA` shot
reason, and penalty kicks are Phase 39 scope per `ROADMAP.md`. This is a dependency constraint, not
a scope reduction: the table is built so the Phase 39 phase value is one row, and Task 2 records
the follow-up explicitly rather than letting it disappear.

## Ordering note — the corner row

`CORNER_KICK_CLEAR_OUT` only becomes the corner sequence's entry phase when plan 38-20 lands
(wave 15). Until then the corner row exists but is unreachable in a live game; the tests seed the
phase directly, and the 38-24 checkpoint verifies the live behaviour after 38-20 has landed. Do
NOT also add `CORNER_KICK_GK_SETUP_ATTACKING` as a hedge — once 38-20 lands, the
`CORNER_KICK_CLEAR_OUT` to `CORNER_KICK_GK_SETUP_ATTACKING` transition would fire a second banner.
