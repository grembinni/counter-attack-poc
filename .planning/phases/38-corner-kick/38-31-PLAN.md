<objective>
Fix the root cause of the Undo regression reported in `38-30-SUMMARY.md` bug 2: `GameState.lastDiceRoll`
is never cleared anywhere in the corner-kick chain, so `CornerKickSetupPanel`'s `canUndoReposition` /
`canUndoFinalSetup` guard (`if (lastDiceRoll) return false;`) is permanently `false` and the Undo control
can never enable — no matter how many placements have been made.

Purpose: this is a direct regression in scope of the third gap-closure round and re-opens D-GAP-01. It
blocks all three sub-findings the verifier reported at once (no visual enablement, no single-undo, no
multi-step stack) because the button is simply never clickable.

Output: `lastDiceRoll` cleared on entry to both corner-kick reversible-move windows, plus engine and
socket-level regression coverage — including the missing LIFO multi-undo test that proves the stepped
stack works against the 38-27 bounded single-destination placement model.
</objective>
