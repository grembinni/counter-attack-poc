<objective>
Wire the client's interaction layer for Corner Kick: the Zustand store's per-phase piece-selection
and valid-destination logic plus the two new socket emitters, and `HexGrid`'s piece-selectability
and hex-highlight rules for all four interactive corner phases.

Purpose: the store and grid are the client's authoritative mirror of server legality. Deriving the
highlight sets from the same field names and caps the server enforces is what keeps client
highlights and server rejections from drifting — the explicit rationale the Phase 37 goal-kick
implementation records for its own mirror.

Output: store branches + emitters + tests, and `HexGrid` selectability/tint wiring using only
existing `HexHighlightType`/`RING_STYLES` members (D-09 forbids adding new tint types).
</objective>
