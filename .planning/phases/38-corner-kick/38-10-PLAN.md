## Trust Boundaries

| Boundary                      | Description                                                                                                                                                   |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| client socket to GAME_UNDO    | An untrusted client can spam `GAME_UNDO` during either corner reposition window; `applyUndo` is the sole authority that decides what state mutation results.  |
