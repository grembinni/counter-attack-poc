  <what-built>
    Five plans landed since the last checkpoint, closing all four bugs you reported:

    - **38-25 — bug 1, the clear-out is now automatic.** The interactive clear-out step is gone
      entirely: no phase, no panel, no clicking, no Confirm. The instant a corner is awarded, every
      player of EITHER team standing within 3 hexes of the corner is moved by the game itself, in a
      straight line toward the goal the corner is being taken at, to the first hex that is on the
      pitch, unoccupied, and clear of the corner area. The corner now opens directly on the attacking
      goalkeeper's reposition window. Each automatic move is written to the action log so Undo and
      replay stay complete.
    - **38-26 — bug 4, the ActionLog crash is fixed.** The log had no formatter for the clear-out
      move event, so it returned nothing and crashed the whole log panel. The formatter is added.
      The compiler now proves every event type has a formatter, so this class of crash cannot ship
      again unnoticed.
    - **38-27 / 38-29 — bug 2, repositioning is now free-kick-style.** During the 2-2-2 window you
      pick a player and then pick ONE destination hex, at any distance, anywhere inside the allowed
      area — exactly like a free kick. The one-hex-at-a-time walking is gone. The player is marked
      activated the moment that single placement lands, not before, and is then done for the rest of
      the window.
    - **38-29 — bug 3, the pre-kick move no longer marks activation.** A player moved during the
      final 3-hex window never shows the orange-ring/red-X activated marker at any point. The
      one-player-per-team limit for that window is unchanged.
    - **38-28 — the Corner Kick banner was re-homed, not lost.** The banner used to be triggered by
      entering the clear-out phase. Since that phase no longer exists, it is now triggered by
      entering the attacking goalkeeper window, so it still appears exactly once per corner.

    Three things had to be decided without you this round. Each is flagged in the steps below and
    needs an explicit ruling:

    - **A-AUTO-01** — "3 hexes clear" is implemented as ending up MORE than 3 hexes from the corner
      (so 4 or more). This matches the existing rule that no defender may be within 3 hexes.
    - **A-GAP3-BUDGET** — the reposition budget is UNCHANGED: 2 distinct players per round, 3 rounds
      per side, 6 distinct players per side in total.
    - **A-GAP3-AREA** — "allowed area" is implemented exactly as free kick does it: the attacking
      side may place a player on any unoccupied hex on the pitch; the defending side on any
      unoccupied hex that is not within 3 hexes of the corner.
