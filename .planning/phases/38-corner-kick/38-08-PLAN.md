<objective>
Prove the whole Corner Kick flow works end to end at the socket-handler level, exercising the
same event sequence a real client produces, from the byline exit that awards the corner through to
the header contest or ball delivery.

Purpose: the unit suites in 38-02..38-06 each verify one function or one component in isolation.
The recurring failure mode in this codebase is a new phase that works function-by-function but is
unreachable end to end because a registration list or handler branch was missed. This is the test
that catches that.

Output: `cornerKick.integration.test.ts`, mirroring `goalKick.integration.test.ts`'s structure,
with at least one end-to-end assertion per phase requirement.
</objective>
