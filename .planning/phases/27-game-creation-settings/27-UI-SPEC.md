**shadcn gate outcome:** No `components.json` or `tailwind.config.*` exists anywhere in the repo. This is phase 27 of 30 — 26 prior phases (including the two screens this phase directly modifies, `TeamSelectionScreen.tsx` and `UniformSelectionScreen.tsx`) established a consistent hand-rolled dark-theme CSS Modules system. Introducing shadcn/Tailwind now would fork the design system mid-project and contradict `LobbyScreen`/`TeamSelectionScreen`/`UniformSelectionScreen`/`GameBoard` conventions already in place. Decision: **decline shadcn init, continue the existing CSS Modules system.** Flag to user if this default is unwanted — re-run with shadcn init accepted.

## Spacing Scale

Declared values (must be multiples of 4) — extracted from the existing codebase (`LobbyScreen.module.css`, `TeamSelectionScreen.module.css`):

| Token | Value | Usage                                                                                                                         |
| ----- | ----- | ----------------------------------------------------------------------------------------------------------------------------- |
| xs    | 4px   | Icon-to-label gaps (`.speedIcon` margin), tight inline padding                                                                |
| sm    | 8px   | Compact spacing (`.tabs` gap, `.speedSelector`→`.speedOptions` internal gaps use 6-12px cluster, round to 8 for new elements) |
| md    | 16px  | Default element spacing (`.screen` gap, `.grid` gap, card padding)                                                            |
| lg    | 24px  | Section/page padding (`.screen` padding, `.card` padding in LobbyScreen)                                                      |
| xl    | 32px  | Layout gaps between major settings-screen sections (new for this phase)                                                       |

Exceptions: existing speed-selector uses `6px`/`10px`/`12px` in a few spots (`.speedOptions` gap: 6px, `.ctaButton` padding: 10px 20px, `.speedSelector` gap: 12px) — these are pre-existing, do not "fix" them, but **new elements built in Phase 27 must use only 4/8/16/24/32.**

## Typography

Matches the established scale used across `LobbyScreen`, `TeamSelectionScreen`, `UniformSelectionScreen` verbatim — do not introduce new sizes/weights for this phase.

| Role                              | Size | Weight | Line Height                                                                                                                    |
| --------------------------------- | ---- | ------ | ------------------------------------------------------------------------------------------------------------------------------ |
| Body / label                      | 13px | 400    | 1.4 (existing `.body`/`.statusLine` have no explicit line-height; default browser ~1.4 is acceptable — do not add a new value) |
| Emphasis / active state           | 13px | 700    | 1.4                                                                                                                            |
| Heading                           | 20px | 700    | 1.2                                                                                                                            |
| Display (room code / brand title) | 28px | 700    | 1.2                                                                                                                            |

Note: the template's 4-tier Body/Label/Heading/Display slots are filled from the codebase's actual usage — this project does not have a separate 14px/16px tier; 13px is used for all body/label text everywhere in Lobby/TeamSelection/UniformSelection. New settings-screen copy (read-only subheader, checkbox labels, pool section headers) must reuse 13px/400 (body) and 13px/700 (emphasis/active) exactly — no new intermediate size.

## Color

Matches the existing dark theme verbatim (documented at the top of `TeamSelectionScreen.module.css`):

| Role                  | Value                                        | Usage                                                                                                                                        |
| --------------------- | -------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| Dominant (60%)        | `#1a1a2e`                                    | Page background (`.screen`, `.page`)                                                                                                         |
| Secondary (30%)       | `#16213e`                                    | Cards, surfaces (`.card`, subheader/summary block backgrounds, checkbox row backgrounds)                                                     |
| Accent (10%)          | `#f5c518` (gold)                             | Reserved for: brand title (`landingTitle`), room code display only. **Not used** for the settings screen's interactive elements — see below. |
| Interactive accent    | `#0f3460` (dark blue) fill / `#1a56b0` hover | Primary CTA buttons (`.ctaButton`), borders on cards/surfaces, active-tab underline                                                          |
| Destructive           | `#ef4444` (red)                              | Reserved for error text only (`.errorText`) — no destructive actions exist in this phase (no delete/reset/confirm-to-discard flow)           |
| Text primary          | `#e0e0e0`                                    | Headings, active labels                                                                                                                      |
| Text dim              | `#a0a0a0`                                    | Secondary/status/disabled-adjacent text                                                                                                      |
| Speed-slow accent     | `#3b82f6` / active `#93c5fd`                 | Slow speed option only (existing `.speedColorSlow`)                                                                                          |
| Speed-standard accent | `#22c55e` / active `#86efac`                 | Standard speed option only (existing `.speedColorStandard`)                                                                                  |
| Speed-fast accent     | `#f97316` / active `#fdba74`                 | Fast speed option only (existing `.speedColorFast`)                                                                                          |

Accent reserved for: gold (`#f5c518`) is reserved for brand title and room-code display ONLY — do not apply it to the new settings screen's Confirm button, checkboxes, or team-type toggle. The settings screen's primary CTA ("Confirm Settings") uses the existing `.ctaButton` treatment (`#0f3460` fill, `#1a56b0` hover), matching every other primary action button in the app (Create Game, Join Game, Generate Room Code).

Team-type toggle (Standard / Draft) and draft-pool checkboxes reuse the existing tab-bar pattern (`.tab` / `.tabActive` — text-color + underline change, no background fill) rather than inventing a new toggle component, for visual consistency with the MLS/International tabs on `TeamSelectionScreen`.

## Interaction Notes (phase-specific, supplements copywriting/color contract)

- **Screen placement:** New `GAME_SETTINGS` screen (Zustand `Screen` union member, per CONTEXT.md code_context) renders host-only, immediately after Create Room, before a joiner is required (D-01). Use the same `.page` / `.card` centered-column shell as `LobbyScreen.tsx` for visual consistency with the screen it's inserted after.
- **Joining player never sees this screen** (D-02) — no UI contract needed for the joiner's view of the settings step itself; they receive confirmed settings via the room/join payload and see only the resulting read-only subheaders on `TeamSelectionScreen`/`UniformSelectionScreen`.
- **Locked-after-confirm (D-03):** once "Confirm Settings" is clicked, the settings screen is left permanently (no back-navigation into it for the rest of the match) — no `subLink` "&larr; Back" affordance should be added to this screen for the host once the room exists (differs from `CreateRoomScreen`'s back link, which is pre-room-creation only).
- **Draft pool checkboxes (D-04/D-05/D-06):** all 5 shown; Legends/Icons rendered with the existing `disabled` + reduced-opacity treatment already used for `.card:disabled` (`opacity: 0.4`) plus the "(coming soon)" copy; Original pre-checked on mode switch to Draft; Confirm button `disabled` whenever the 3 enabled checkboxes are all unchecked (mirrors the existing `.ctaButton:disabled` opacity-0.5 pattern from `LobbyScreen`).
- **Scoreboard speed mention (D-08):** soft requirement — attempt a small read-only speed label in the existing `.scoreboard` band (`GameBoard.module.css`) using the same 13px/dim-text treatment; if it does not fit without layout rework, omit and note as a follow-up per CONTEXT.md discretion.
