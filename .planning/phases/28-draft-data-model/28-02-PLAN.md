A single filter pass over `PLAYER_POOL` (each player appears once in `PLAYER_POOL`, so no cross-pool duplicate is possible) satisfies the dedupe requirement.

    Export `function assignTiers(players: PoolPlayer[]): TieredPoolPlayer[]` (D-05/D-06/D-07/D-08). Steps: (1) split into `keepers = players.filter(role === 'GK')` and `outfield = players.filter(role !== 'GK')` — GK exclusion per D-08. (2) Rank outfield: create a copy sorted DESCENDING by `computeTotalStat` using a stable comparator (`computeTotalStat(b) - computeTotalStat(a)`); JS Array.prototype.sort is stable, so equal-stat players retain their input-array order — this is the D-06 tie-break (rank/id order, NOT value-based). (3) For the sorted outfield array of length `N`, the player at zero-based index `i` has `percentileRank = ((N - i) / N) * 100` (so index 0 = 100, the last index → the smallest positive value). Assign tier: `percentileRank >= TIER_PERCENTILE_BOUNDS.chase` → `'chase'`, else `>= TIER_PERCENTILE_BOUNDS.rare` → `'rare'`, else `>= TIER_PERCENTILE_BOUNDS.uncommon` → `'uncommon'`, else `'common'`. Guard `N === 0` (no outfield) to avoid divide-by-zero. (4) Build a `Map<playerId, DraftTier>` from the ranked outfield plus `'keeper'` for every GK. (5) Return `players.map(...)` in the ORIGINAL input order, each spread into a `TieredPoolPlayer` with `tier` from the map and `totalStat: computeTotalStat(player)`. Do not mutate the input array or `PLAYER_POOL`.
