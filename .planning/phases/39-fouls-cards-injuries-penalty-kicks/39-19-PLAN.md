<objective>
Close UAT gap 8: replace `isProfessionalFoul`'s omnidirectional "could any teammate have reached the foul hex" test with the goal-side + goal-path test the user specified, excluding the goalkeeper.

Purpose: today ANY teammate anywhere on the pitch with enough pace suppresses DOGSO, including one standing behind the attacker running the other way. The rule the user wants is directional — only defenders between the attacker and the goal they are attacking count, and only if their movement can actually intercept the attacker's run at the goal.

Output: a rewritten `isProfessionalFoul` plus two exported helpers, with the user's own worked example locked in as a unit test.

## Rule specification (derived from 39-UAT test 8, resolved)

`39-UAT.md` flagged this rule as needing a spec pass because the worked example was ambiguous. It resolves cleanly against this codebase's geometry — the resolution is recorded here so the executor implements it without re-deriving:

- `q` is the horizontal axis (0..36); `r` is the vertical axis (0..25). The user's `(X,Y)` notation is `(q,r)`.
- Home attacks `q = 36`, away attacks `q = 0` — the existing `goalQ = attackingTeam === 'home' ? 36 : 0` convention used by `applyDeclareShot`, `applySnapshot` and `applyResolveHeaderTarget`.
- The attacker's goal path is the straight hex line from the attacker's hex (with `r` clamped to 5..20) to the goal column at the SAME clamped `r`.
- The user's worked example reads "Defender at (29,12) with move 4 is within range of (29,25)". `(29,25)` is a transcription slip for `(29,15)`: `hexDistance({q:29,r:12},{q:29,r:25})` is 13 (unreachable with pace 4), whereas `hexDistance({q:29,r:12},{q:29,r:15})` is 3 (reachable with pace 4), and `hexLine({q:21,r:15},{q:36,r:15})` provably contains `{q:29,r:15}` under this repo's ODD-Q `toCube`/`fromCube` conversion. The corrected example is the canonical test case below.
- The user's "(a) ... OR (b) ..." phrasing and 39-UAT's "(a) ... AND (b) ..." restatement collapse to one predicate, because (b) is vacuous when (a) holds: **DOGSO is true exactly when NO non-goalkeeper defender is both horizontally closer to the attacked goal than the attacker AND able to reach any hex of the attacker's goal path within their remaining pace.** Implement that single predicate.
  </objective>
