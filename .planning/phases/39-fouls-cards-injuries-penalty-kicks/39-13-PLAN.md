<objective>
Make the foul chain reachable over sockets: feed `applyMove` the two additional server-generated dice it now needs, and add the `GAME_FOUL_CHOICE` handler that routes the fouled manager's decision.

Purpose: `resolveFoulChain` (Plan 39-10) reads `dice.injuryDie` and `dice.bookingDie`. Those must be rolled with `crypto.randomInt` on the server in the same `GAME_MOVE` invocation that resolves the duel, so the whole foul chain commits in one `broadcastState` — which is precisely what makes the EventBanner multi-event fix (Plan 39-04) necessary.

Output: the dice wiring, the choice handler, and a socket-level integration suite proving FK-01.
</objective>

Two changes in `gameHandlers.ts`.

1. `GAME_MOVE` dice payload. Wherever the handler builds the `dice` object it passes to `applyMove`, add `injuryDie: rollDice()` and `bookingDie: rollDice()` alongside the existing `stealDie`/`tackleDie`/`carrierDie`. Roll them unconditionally, exactly as the existing dice are rolled unconditionally regardless of whether the move turns out to trigger a duel — `resolveFoulChain` ignores them when no foul occurs, and unconditional rolling keeps the handler free of rule logic. Add a comment recording that these are the FRESH dice REQUIREMENTS.md INJURY-01/CARD-01 call for, distinct from the trigger die, and that they must never come from the client.

2. New `socket.on(ClientEvents.GAME_FOUL_CHOICE, (choice: 'continue' | 'restart') => { ... })`, copying `GAME_GK_DIVE`'s five-step shape:
   - `roomCode`/room lookup; `if (!room || room.isProcessing) return;`; `room.isProcessing = true`; `try` / `finally { room.isProcessing = false; }`.
   - Null-state guard → `GAME_ERROR` `WRONG_PHASE` + `broadcastState`.
   - Phase guard `room.gameState.phase !== 'FOUL_CHOICE'` → `WRONG_PHASE` + `broadcastState`.
   - Payload allow-list (ASVS V5): `choice !== 'continue' && choice !== 'restart'` → `INVALID_CHOICE` + `broadcastState`. Use an explicit two-value comparison, not a `typeof` check — this mirrors how `GAME_GK_RESTART`'s `'kick' | 'throw' | 'movement'` payload is validated.
   - Team guard: the decision belongs to the FOULED side, which `resolveFoulChain` set as `attackingTeam`. Reject with `WRONG_TEAM` + `broadcastState` when `socketTeam(socket) !== room.gameState.attackingTeam`.
   - `applyFoulChoice(room.gameState, choice)`; on `!ok` emit `result.reason` + `broadcastState`; on success assign `room.gameState = result.state` and `broadcastState`.
   - If the resulting phase is `FULL_TIME`, call `startReplayStream(io, room)` — a foul resolved on the action that crosses full time can end the match, matching the existing pattern in `GAME_GK_DIVE` and `GAME_END_TURN`.

Import `applyFoulChoice` alongside the existing `gameEngine` imports.
