3. New `socket.on(ClientEvents.GAME_PENALTY_KICK_TAKER, (pieceId: string) => { ... })` — full five-step shape copied from `GAME_GK_DIVE`:

   - Null-state guard → `WRONG_PHASE` + `broadcastState`.
   - Phase guard `!== 'PENALTY_KICK_TAKER_SELECT'` → `WRONG_PHASE` + `broadcastState`.

Never read a die value from the client payload.

Import the five engine functions at the top of `gameHandlers.ts` alongside the existing `applyGoalKickReposition`/`applyCornerKickReposition` imports.
