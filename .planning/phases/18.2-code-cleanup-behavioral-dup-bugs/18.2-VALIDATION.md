## Sampling Rate

- **After every task commit:** Run the quick command for the specific test file(s) touched by that task (e.g. `npx vitest run src/store/useGameStore.test.ts` for a BUG-09 task)
- **After every plan wave:** Run the full suite for each affected package
- **Before `/gsd-verify-work`:** All 3 packages' full suites green (320/454/225 baseline + new tests)
- **Max feedback latency:** ~20 seconds
