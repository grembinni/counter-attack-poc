<objective>
Rewrite the pure draft-session state machine (`draftSession.ts`) from the fixed 4-cycle model to the round-aware 6-round model, and delete the DRAFT-08 keeper-safety-net mechanic outright (superseded by the dedicated round-1 GK pack round, D-21).

Purpose: This module is the server-side, side-effect-free state machine that mirrors `gameEngine.ts`'s separation from `roomHandlers.ts`. It must support a variable pick-count per round (2 in round 1, 3 in rounds 2-6) and drop the entire keeper-safety vertical (function, session fields, view projection). It also fixes the pack-to-player assignment from a global cross-round shuffle to a per-round coin-flip (a genuine correctness fix under per-round composition).

Output: A round-driven `advanceSubStep`/`openNextRound`, a per-round `assignRoundPackOrder`, keeper-free `createDraftSession`/`applyPick`/`getSide`/`withSide`/`buildDraftView`, and a rewritten unit test suite.
</objective>
