<objective>
Implement OFFSIDE-02: the free-kick consequence of an offside foul. When a flagged-offside piece (flag set by plan 17-05) gains possession of the ball — via any grounded pass pickup, a loose-ball pickup, or a won header — the server immediately awards a free kick to the opposing team from the offside player's hex, enters a both-teams repositioning phase with the D-30/D-31 zone rules, and then restricts the kicking team to STANDARD_PASS / HIGH_PASS / LONG_BALL / SHOT (D-32).

Purpose: Close the offside rule. Detection (17-05) is inert without a consequence. This plan adds the `FREE_KICK_SETUP` phase, the `triggerOffsideFoul` transform invoked at every possession-gain point, the placement validator mirroring `applyKickOffReady`, the both-ready handshake, and the client setup + restricted-action UI.
Output: `FREE_KICK_SETUP` phase + `freeKickHex`/`freeKickAttackingTeam` fields, `triggerOffsideFoul`, `applyFreeKickReady`, two new socket events + handlers, ActionPanel FREE_KICK_SETUP branch + restricted PASS action set, store emit actions.
</objective>
