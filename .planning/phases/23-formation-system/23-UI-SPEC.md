# Phase 23 — UI Design Contract

> Visual and interaction contract for the Formation Selection section added to UniformSelectionScreen.
> Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Scope Note

Phase 23 does NOT introduce a new screen. It inserts a **Formation section** into the existing
`UniformSelectionScreen.tsx` between the Team grid and the Style grid (Decision D-05). All design
values below are extensions of the Phase 22 design system already implemented in
`UniformSelectionScreen.module.css`.

## Spacing Scale

Declared values — multiples of 4, consistent with Phase 22 established tokens:

| Token | Value | Usage                                                                   |
| ----- | ----- | ----------------------------------------------------------------------- |
| xs    | 4px   | Speed icon margin-right                                                 |
| sm    | 8px   | Style tile gap, card padding internal                                   |
| md    | 16px  | Section gap (screen flex column `gap: 16px`), banner padding horizontal |
| lg    | 24px  | Screen padding                                                          |
| xl    | 32px  | Not currently used on this screen                                       |
| 2xl   | 48px  | Not currently used on this screen                                       |
| 3xl   | 64px  | Not currently used on this screen                                       |

Formation-specific spacing:

| Context                          | Value | Rationale                                                      |
| -------------------------------- | ----- | -------------------------------------------------------------- |
| Formation grid gap               | 10px  | Matches `.teamGrid` gap (10px) — same card density feel        |
| Formation card padding           | 8px   | Matches `.teamCard` padding (10px) — 8px preserves image space |
| Formation image height           | 100px | Legible pitch diagram at 4-card-wide grid                      |
| Formation label margin-top       | 8px   | Tight coupling between image and label; on 4px grid            |
| Formation description margin-top | 4px   | Label + description read as a unit; on 4px grid                |

### Spacing Exceptions

Values that deviate from the 8-point (multiples of 4) grid require an explicit named exception:

| Named Exception        | Value | Rationale                                                                                                       |
| ---------------------- | ----- | --------------------------------------------------------------------------------------------------------------- |
| Formation image height | 100px | Fixed height maximises pitch diagram legibility at the available card width; not a spacing token                |
| Formation grid gap     | 10px  | Matches the established `.teamGrid` gap from Phase 22 (`gap: 10px`); aligns card density feel across both grids |

All other formation-specific spacing values (`8px` card padding, `8px` label margin-top, `4px` description margin-top) are on the 4px grid and require no exception.

## Color

All color values inherited from Phase 22. No new palette tokens introduced.

| Role               | Value                             | Usage                                                      |
| ------------------ | --------------------------------- | ---------------------------------------------------------- |
| Dominant (60%)     | `#1a1a2e`                         | Page background (`.screen` background)                     |
| Secondary (30%)    | `#16213e`                         | Card backgrounds, banner background, style tile background |
| Border / structure | `#0f3460`                         | Default card borders, style tile borders                   |
| Text primary       | `#e0e0e0`                         | Headings, labels, active button text                       |
| Text dim           | `#a0a0a0`                         | Section labels, status lines, inactive speed options       |
| Accent (10%)       | team `palette.homePrime` (inline) | Selected card border and box-shadow glow only              |
| Destructive        | not applicable                    | No destructive actions in this phase                       |

Accent reserved for: **selected formation card border-color and box-shadow only**. The glow
pattern is identical to `.teamCardSelected` (white-based glow) — formation cards use the same
`rgba(255, 255, 255, 0.9)` border with `rgba(255, 255, 255, 0.45)` box-shadow, not the team
palette color. This matches the team card selection pattern (which also uses white glow, not team
color), keeping the formation section visually consistent with the team grid above it.

Rationale: style tiles use inline `palette.homePrime` for their selected border (because a team
is always selected before a style). Formation cards are selected before (or independently of)
a team pick, so white glow is the safe fallback — matches team card behavior.

Source: `UniformSelectionScreen.module.css` `.teamCardSelected` (lines 84–97).

## Interaction States

### Formation Card States

| State                | Visual                                                                         | Trigger                                        |
| -------------------- | ------------------------------------------------------------------------------ | ---------------------------------------------- |
| Default (unselected) | `rgba(255,255,255,0.2)` border, no glow                                        | Initial render (non-4-4-2 cards)               |
| Selected             | `rgba(255,255,255,0.9)` border + `0 0 0 2px rgba(255,255,255,0.45)` box-shadow | User click, or default `'4-4-2'` on mount      |
| Hover (unselected)   | `0 0 0 3px rgba(255,255,255,0.55)` box-shadow                                  | Mouse hover on non-selected, non-disabled card |
| Disabled             | `opacity: 0.5`, `cursor: not-allowed`                                          | After `hasConfirmed = true`                    |
| Away-locked          | `opacity: 0.5`, `cursor: not-allowed`                                          | `awayLocked === true` (home not yet confirmed) |

All transition timing: `box-shadow 0.15s ease, opacity 0.15s ease` — matches Phase 22 card transitions.

### Confirm Button Gate

The Confirm button remains disabled until ALL THREE selections are made:

- `selectedTeam !== null`
- `selectedFormation !== null` (always truthy — pre-selected to `'4-4-2'`)
- `selectedStyle !== null`

The formation pre-selection means the Confirm button gate is functionally unchanged from Phase 22
(team + style still gates the button; formation is always present). Executor must add
`formationId: selectedFormation` to the emit payload.

### No Formation Struck-Out State

Unlike team and style cards, formation cards have no struck-out state. Both players may select
any formation independently — there is no "opponent took this formation" restriction.
The `formationCardStruckOut` class is not needed and must not be created.
