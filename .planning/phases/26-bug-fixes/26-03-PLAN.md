<objective>
Fix three client-side display/interaction defects:

- BUG-25: the MOVE-phase End Turn button hard-codes the green (ready) style, so it is green
  even while move options remain. It must use `ctaButtonClass(remaining)` like the other
  End Turn buttons — yellow while options remain, green only when exhausted.
- BUG-26: clicking an opponent's activated player falls through to a no-op. It must open
  that player's stats panel via `inspectPiece`.
- BUG-27: the deflection log entry must consistently render `failed to deflect — [reason]`
  rather than a bare `failed to deflect` on any path.

Purpose: Correct visible move-slot state, opponent stat inspection, and deflection log
formatting (BUG-25, BUG-26, BUG-27).
Output: Three focused client fixes with regression tests.
</objective>
