## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage                                                             |
| ----- | ----- | ----------------------------------------------------------------- |
| xs    | 4px   | Icon gaps, inline padding, log entry vertical padding             |
| sm    | 8px   | Compact element spacing, top-band internal gaps                   |
| md    | 16px  | Default element spacing, section padding, pitch container padding |
| lg    | 24px  | Overlay card internal padding, section breaks                     |
| xl    | 32px  | Layout-level gaps                                                 |
| 2xl   | 48px  | Major section breaks (not used in top band)                       |
| 3xl   | 64px  | Page-level spacing (not used in top band)                         |

Exceptions:

- Top band total height: 80px (fits desktop 1080p; leaves ~1000px for pitch). Source: CONTEXT.md discretion note — "top band ≤ 80–100px". 80px chosen for maximum pitch height.
- Score columns (home/away): 56px wide, fixed. Enough for 2-digit score + team name label.
- Log section collapsed width: 32px (chevron button only). Expanded width: 240px. Source: CONTEXT.md discretion note — "200–280px when expanded". 240px midpoint chosen.
- Overlay card max-width: 440px (inherits from existing HalfTimeScreen/FullTimeScreen card pattern).
- Connection status dot: 10px × 10px (inherited from ConnectionStatus.module.css).

## Layout Contract

### Top Band Structure (80px height, full viewport width)

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ [ScoreCol 56px] [CenterSection ~35%] [PlayerCard ~20%] [ActionSection flex] [LogToggle] [ScoreCol 56px] │
└─────────────────────────────────────────────────────────────────────────────┘
```

CSS grid approach: `grid-template-columns: 56px 1fr 1fr 1fr auto 56px`

All sections: `align-items: center`, `background: #16213e`, separated by `1px solid #0f3460` borders.
Top band: `background: #1a1a2e`, `height: 80px`, `flex-shrink: 0`, `display: grid`.

### ScoreColumn (both home and away)

- Width: 56px fixed
- Layout: flex column, center-aligned
- Line 1: Team name (11px, 400, `#a0a0a0`)
- Line 2: Score numeral (20px, 700, team color, Courier New)
- Home background tint: none (uses dominant background)
- Home text: `#1a56b0`; Away text: `#c0392b`

### CenterSection (~35% of middle)

Three stacked lines, vertically centered within 80px band:

- **Line 1 (clock):** MM:SS display — 20px, 700, `#f5c518`. Format: `${actionCount}:00`. Always visible. No PLAY_PHASES filter.
- **Line 2 (connection):** ConnectionStatus component — dot (10px) + label (11px, 400, `#a0a0a0`). Compact, not dominant.
- **Line 3 (phase summary):** Active team name colored (13px, 700, team color) + phase label (13px, 400, `#a0a0a0`, uppercase, letter-spacing 0.05em) + moves remaining if MOVEMENT phase (13px, 400, `#a0a0a0`).

### CompactPlayerCard (~20% of middle)

- Background: `#16213e`, border: `1px solid #0f3460`, border-radius: 4px
- Header row: piece name (13px, 700, `#e0e0e0`) + role (11px, 400, `#a0a0a0`, uppercase)
- Stats grid: `display: grid; grid-template-columns: repeat(2, 1fr); gap: 2px 8px`
- Each cell: label (11px, 400, `#a0a0a0`) + value (11px, 700, `#f5c518`)
- Skills: SPD | SHT / TAC | HED / PAS | STM (2 columns, 3 rows)
- State: persists last-selected piece; never blank after first selection. Shows placeholder text "Select a piece" (11px, 400, `#a0a0a0`) before first selection.
- Padding: 8px

### ActionSection (flex-grow remainder)

- Background: `#16213e`, border: `1px solid #0f3460`, border-radius: 4px
- Phase swap: `{phase === 'KICK_OFF_SETUP' ? <KickOffSetupPanel /> : phase === 'REPLAY' ? <ReplayPanel /> : <ActionPanel />}`
- Components render in compact mode — no section title required; context is clear from top band position
- Padding: 8px

### LogToggle

- **Collapsed state (default):** 32px wide, full band height. Contains a single `›` chevron button (13px, 700, `#a0a0a0`) pointing left (expand direction). No other content visible.
- **Expanded state:** 240px wide. Shows ActionLog panel — last 10 log entries visible, scroll for older. Collapse button: `‹` chevron at top-right of expanded panel.
- Transition: no animation (instant show/hide via CSS display or conditional render — no motion in this phase per REQUIREMENTS.md out-of-scope).
- Background expanded: `#16213e`, border: `1px solid #0f3460`.

### Pitch Area

- `flex: 1`, `overflow: hidden`, `display: flex`, `align-items: center`, `justify-content: center`
- Background: `#0a0a0a` (existing)
- Padding: 16px (existing)
- Contains hex grid SVG + PhaseOverlay when active

### PhaseOverlay (HALF_TIME / FULL_TIME)

- Position: `position: absolute; inset: 0; display: flex; align-items: center; justify-content: center; z-index: 10`
- Backdrop: `background: rgba(0,0,0,0.6)`
- Card: inherits `.card` dimensions from HalfTimeScreen/FullTimeScreen — max-width 440px, `background: #16213e`, `border: 1px solid #0f3460`, `border-radius: 4px`, `padding: 24px`, `gap: 16px`
- Heading: 20px, 700, `#e0e0e0`
- Score: 28px, 700, `#e0e0e0`, Courier New
- Body: 13px, 400, `#a0a0a0`, line-height 1.5
- CTA button: inherits existing `.ctaButton` pattern

## Interaction Contract

### Clock

- Update trigger: every `game:state` WebSocket broadcast (event-driven, no client timer)
- Display formula: `String(actionCount).padStart(2, '0') + ':00'`
- Second half: actionCount continues past 45; display follows naturally (e.g. 46 → "46:00")
- Always rendered — no phase gating

### Log Toggle

- Click chevron `›` → expand log, chevron becomes `‹`
- Click chevron `‹` → collapse log, chevron becomes `›`
- State: local `useState` in GameBoard (not in Zustand — UI-only state)
- Default: collapsed

### Player Card

- Updates on `selectedPieceId` change in Zustand store
- On deselection: retains last piece data (never clears)
- Before any selection: shows "Select a piece" placeholder text

### Phase Overlay

- Rendered when `phase === 'HALF_TIME'` or `phase === 'FULL_TIME'`
- Rendered inside the `pitchContainer` div, not above the top band
- The top band (including clock) remains visible above the overlay
- CTA ("Start 2nd Half" / "View Match"): button at bottom of overlay card

### App Routing

- Remove `screen === 'HALF_TIME'` and `screen === 'FULL_TIME'` branches from App.tsx
- Both phases render `<GameBoard />`
- REPLAY already routes through GameBoard — no change
