<objective>
Stop the standard-mode pregame (Step 3) lineup screen fabricating a client-side jersey number for the placeholder bench from `PoolPlayer.number`, so no bench player is ever shown a number that later changes.

Purpose: Plan 48-02 makes the server draw standard-mode bench numbers randomly in `[15, 99]` at `LINEUP_CONFIRM`. The pregame screen renders BEFORE that draw and currently computes its own display numbers (`pregameBenchNumbers[p.id] = p.number`, i.e. the authored 12-16 pool identity values). Output: Two deleted lines plus one removed prop in `LineupAssignmentScreen.tsx`, and a regression test proving the pregame bench renders names but no `#n`.
</objective>
