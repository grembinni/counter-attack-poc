<objective>
Make `applySubstitution` treat the jersey number as a property of the person rather than of the slot: the incoming substitute keeps their own bench number when they take the field, and the outgoing player's new bench card shows their own number.

Purpose: 48-RESEARCH.md Pitfall 4 traced two live NUMBER-02 violations that 48-CONTEXT.md's canonical file list did not enumerate. (1) The incoming piece is built as `{ ...outPiece, ... }`, so it silently inherits the vacated slot's number. (2) The outgoing player's replacement bench entry is built with `jerseyNumber: benchEntry.jerseyNumber` — but `benchEntry` is the INCOMING player's entry, so the departing player's bench card wears someone else's number. Both are documented in-source as intentional (the SUB-03 contract), which this plan supersedes.
Output: Two explicit overrides in `applySubstitution`, a rewritten SUB-03 docstring, and rewritten unit + integration assertions.
</objective>
