<objective>
Close GAP-2 (CR-01): the three tackle/steal success return paths in `applyMove` (gameEngine.ts lines 685, 768, 829) increment `actionCount` by `GAME_SPEED_MINUTES[state.gameSpeed]` and return `phase: 'PASS'` directly, without checking whether the new `actionCount` has crossed `halfEnd`.

Purpose: In Fast mode (+3 min/action), when `actionCount` is already in added time, a successful tackle can push the clock past `halfEnd` yet the half never ends — because the half-end check lives only in `applyEndTurn` (nextSlot === null), which is never re-entered if the team with the ball only passes. This is a clock-freeze correctness failure for the UX-07 game-speed feature.

Output: `gameEngine.ts` with a half-end check applied in each of the three tackle/steal success paths, mirroring `applyEndTurn`'s existing logic (lines 916-948).
</objective>
