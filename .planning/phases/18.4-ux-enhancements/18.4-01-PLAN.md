<objective>
Implement UX-07: a Slow / Standard / Fast game-speed selector (default Standard) on the
team-selection screen that controls how many match-clock minutes elapse per completed MOVE
action — Slow = +1, Standard = +2, Fast = +3 (per 18.4-CONTEXT.md UX-07, locked).

Purpose: Give players control over match pacing. The match clock is event-driven off
`actionCount` (Phase 13 D-08/D-09: minutes = actionCount, seconds always `:00`), so this is a
multiplier/lookup change on the existing per-MOVE `actionCount` increment, NOT a new timer or
animation system (CLAUDE.md: "static state updates only").

Output: A new `GameSpeed` type + `GameState.gameSpeed` field + `GAME_SPEED_MINUTES` lookup in
shared; server threads the picked speed through `TEAM_PICK` → `buildInitialGameState`; the
`+3` literals at MOVE-completion sites become `GAME_SPEED_MINUTES[gameSpeed]`; a three-button
selector on `TeamSelectionScreen.tsx`.
</objective>
