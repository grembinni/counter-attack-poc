## Decisions Made

- **1s vs 2s duration:** 18.4-CONTEXT.md mentions "2-second" transient duration, but 18-UI-SPEC.md (the approved design contract) specifies 100ms/800ms/100ms = 1000ms total. Followed UI-SPEC per plan instruction; the discrepancy is noted here.
- **@keyframes over CSS transition:** `@keyframes bannerFade` with `animation: 1000ms ease forwards` gives precise hold-timing without multiple JS timers for in/hold/out phases. A single `setTimeout(1000ms)` handles DOM removal.
- **role="status" aria-live="assertive":** Added for accessibility — screen readers announce match events without requiring visual attention to the banner.
