## What Was Built

### Task 1: UX-09 Final-Third Markers

Two new `<line>` elements added to `PitchMarkings.tsx` alongside the existing halfway line and pitch markings layer. The lines render as red vertical lines at the home and away final-third boundaries:

- **Home edge:** x=315 (boundary between q=10 `homeThird` and q=11 `middleThird`)
- **Away edge:** x=765 (boundary between q=25 `middleThird` and q=26 `awayThird`)

Both x-coordinates are derived from the same hex-to-pixel formula that produces x=540 for the halfway line: `HEX_SIZE (20) * 1.5 * q_col + 15` (column midpoint pitch). The boundary between adjacent columns A and A+1 is `30*A + 15`.

Constants `HOME_THIRD_X = 315` and `AWAY_THIRD_X = 765` are declared at module level with a derivation comment. Both lines use: `stroke="#ef4444"`, `strokeWidth={3}`, `strokeOpacity={1}`, `fill="none"`, `pointerEvents="none"`, `y1={17.3}`, `y2={883.3}` — matching the full-board-height span of the existing halfway line exactly.

### Task 2: UX-12 Stat Tooltips

Added `STAT_FULL_NAME: Record<string, string>` constant to `GameBoard.tsx` immediately after `PHASE_LABEL`, following the D-02 flat-record pattern. Maps all 9 abbreviations rendered by StatRow call sites to full name plus a short action summary:

| Key | Value                                             |
| --- | ------------------------------------------------- |
| PAC | Pace — how far this player can move per turn.     |
| DRB | Dribbling — keeping the ball under pressure.      |
| AA  | Aerial Ability — winning headers and high passes. |
| SHT | Shooting — scoring power on shots.                |
| SAV | Saving — a goalkeeper's shot-stopping.            |
| HPS | High Pass — accuracy of lofted passes.            |
| RES | Resilience — resisting fatigue and knocks.        |
| TAC | Tackling — contesting the ball from a carrier.    |
| HND | Handling — a goalkeeper's catch reliability.      |

`StatRow`'s `.statLabel` span now has `title={STAT_FULL_NAME[label] ?? label}`. Zero new dependencies, no new CSS classes, no new component files — native browser tooltip only (4x existing precedent in the codebase per UI-SPEC Interaction Contract).

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Smart-quote corruption in STAT_FULL_NAME string literals**

- **Found during:** Task 2 typecheck
- **Issue:** Edit tool inserted Unicode LEFT/RIGHT SINGLE QUOTATION MARK (U+2018/U+2019) instead of ASCII apostrophes (U+0027) as string delimiters in the STAT_FULL_NAME block, causing TypeScript TS1127 "Invalid character" errors on all value lines
- **Fix:** Used a Node.js script to re-encode only the affected lines with ASCII `'` and `"` delimiters while preserving the em-dash content characters
- **Files modified:** `packages/client/src/components/GameBoard.tsx` (byte-level correction, no logical change)
- **Commit:** included in 2f9a3da
