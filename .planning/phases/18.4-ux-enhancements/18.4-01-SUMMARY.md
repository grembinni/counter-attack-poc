# Phase 18.4 Plan 01: Game Speed Selector (UX-07) Summary

**One-liner:** Slow/Standard/Fast game-speed selector on team-selection screen drives per-MOVE clock increment (1/2/3 min) via `GAME_SPEED_MINUTES[gameSpeed]` lookup on `GameState.gameSpeed`.

## What Was Built

UX-07 is fully implemented end-to-end:

1. **Shared types** (`packages/shared/src/types.ts`): `GameSpeed = 'slow' | 'standard' | 'fast'`, `GAME_SPEED_MINUTES` record (slow:1, standard:2, fast:3), and required `gameSpeed: GameSpeed` field on `GameState`.

2. **Socket event** (`packages/shared/src/events.ts`): `TEAM_SPEED_SET: 'team:speed-set'` in `ClientEvents` with typed payload `(speed: GameSpeed) => void` in `ClientToServerEvents`.

3. **Server — game engine** (`packages/server/src/gameEngine.ts`): `buildInitialGameState` now accepts a third `gameSpeed: GameSpeed = 'standard'` parameter and stores it on the returned state. All four MOVE-completion clock sites replaced: `state.actionCount + 3` → `state.actionCount + GAME_SPEED_MINUTES[state.gameSpeed]` (tackle success, BUG-13 additional tackle, steal success, applyEndTurn nextSlot===null branch). Pass-phase `passTimeCost` increments are untouched (UX-07 scopes speed to MOVE actions only).

4. **Server — room handlers** (`packages/server/src/roomHandlers.ts`, `roomStore.ts`): `TEAM_SPEED_SET` handler with ASVS V5 allow-list validation (`VALID_GAME_SPEEDS`) and home-player-only gate (`playerSlot === 1`). Room gains `gameSpeed?: GameSpeed` field; consumed via `room.gameSpeed ?? 'standard'` at TEAM_PICK away-pick → `buildInitialGameState`.

5. **Client — store** (`packages/client/src/store/useGameStore.ts`): `emitTeamSpeed: (speed: GameSpeed) => void` action emitting `ClientEvents.TEAM_SPEED_SET`.

6. **Client — UI** (`TeamSelectionScreen.tsx`, `.module.css`): Three-button speed selector above the team grid. Home player only (gated on `iAmHome`); away player sees disabled buttons. Body typography (13px/400) for label, Emphasis (13px/700) for active option. Buttons carry `aria-pressed` for accessible state and test differentiation. Labels: Slow / Standard / Fast; default: Standard.

7. **Client — App.tsx**: `selectedSpeed` local state (default `'standard'`) co-located with `homePickedTeam` per D-14. `handleSpeedChange` calls both `setSelectedSpeed` and `emitTeamSpeed`. Passed as `selectedSpeed` and `onSpeedChange` props to `<TeamSelectionScreen>`.
