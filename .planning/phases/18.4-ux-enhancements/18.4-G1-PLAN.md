Close GAP-1 (CR-02): remove the React rules-of-hooks violation in `EventBanner.tsx` where `setActive(banner)` is called synchronously during the render function body.

Purpose: State updates during render schedule an extra render and, under React Strict Mode, double-invoke the render — advancing `lastProcessedLengthRef` twice and skipping or mis-firing banner events. Output: `EventBanner.tsx` with the diff logic relocated into an effect; no state mutation during render.
