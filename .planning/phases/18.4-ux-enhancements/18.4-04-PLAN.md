<objective>
Implement UX-08: any End Turn (or header Confirm Selection) that would end a phase while eligible
pieces remain unmoved/unplaced shows a confirmation prompt
("{N} players left to move, are you sure you want to end your turn?") with Cancel (return to the
phase, no state change) and Confirm (proceed). Additionally, the End Turn / Confirm Selection
control renders orange (`#f39c12`) while eligible moves remain and green (`#27ae60`) once all
eligible pieces for that phase have moved/placed.

Applies to every phase that tracks a moved/placed-pieces count: MOVE slots, FREE_MOVE_ATTACK/
FREE_MOVE_DEFENSE, HIGH_PASS_MOVE, FIRST_TIME_PASS_MOVE, GK_KICK_MOVE, and HEADER contestant
confirm-selection (18-CONTEXT.md UX-08). FREE_KICK_SETUP is included where a placed-pieces count
exists.

Purpose: Prevent accidental turn-ending that cuts off remaining moves, and give a persistent
visual signal (orange = incomplete, green = ready) on the primary action control.

Output: an `eligibleRemaining` derivation per phase, a confirm-dialog overlay, a
`ctaButtonClass()` color-state selector, and the `.ctaButtonPending`/`.ctaButtonReady` modifier
classes + dialog CSS.

NOTE: This plan depends on 18.4-03 because both edit `ActionPanel.tsx` (same-file serialization,
different wave). Land 18.4-03 first; this plan builds on that file's post-03 state.
</objective>
