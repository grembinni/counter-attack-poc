<objective>
Fix the FREE_KICK_SETUP flow to match the physical rulebook step sequence identified during Plan 05 UAT. Three problems surfaced:

1. **Missing kicker selection phase:** No distinct step where the kicking team picks the kicker before the 4-move repositioning stage begins.
2. **Stage max wrong:** Stage 0 (kicking) and stage 1 (defending) each allow max=5 moves; the correct limit is 4 (kicker is placed separately as a prior dedicated step, not counted toward the 4 moves).
3. **Undo not gated per-stage:** The Undo button is active even when no moves exist in the current stage, and it can reach across stage boundaries to undo moves from prior stages.

Additionally, the FREE_KICK_SETUP phase has no dedicated ActionPanel render block — the UI falls through without displaying a kicker-select prompt, move counter, or properly gated End Turn button.

Per D-03, this gap plan lives within Phase 25. OFFSIDE-02 cannot close until this plan passes UAT in a subsequent Plan 07.

Purpose: Implement the correct step sequence, stage move caps, undo boundary, and dedicated ActionPanel UI for FREE_KICK_SETUP.
Output: Corrected FREE_KICK_STAGES, new freeKickKickerChosen GameState field, new FK_KICKER_CHOSEN/FK_STAGE_ADVANCE event types, fixed applyUndo boundary, and a complete ActionPanel FREE_KICK_SETUP block.
</objective>
