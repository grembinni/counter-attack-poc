<objective>
Give the match summary its two entry points: an always-available (i) icon on the scoreboard that opens a standalone modal (STATS-01, D-08/D-09), and an inline copy of the same block appended inside the existing half-time and full-time overlay cards (STATS-02, D-10).

Both consume the single `MatchSummaryContent` built in plan 45-04 (D-11). Nothing about the stats rendering is reimplemented here — this plan is chrome and placement only.

The existing half-time and full-time overlay headers stay untouched (D-10): the big score row with team badges, score numerals, the HALF TIME / FULL TIME wording and the clock is preserved exactly as-is, the stats block is appended below it, and the existing proceed controls move down to sit below the appended block.

Purpose: make the summary reachable, in every phase and at both stoppages.
Output: `MatchSummaryModal` plus its CSS, the scoreboard icon row, the two overlay insertions, and a component test suite.
</objective>
