<objective>
Make the "already-moved-this-stage" piece marker visually distinct from the "selected/active" ring (HILITE-03, D-04/D-05). Today both use identical green `#22c55e`, differing only by radius. This plan changes the `isMovedThisStage` layer in `PieceOverlay.tsx` to a dark-grey ring plus a light-grey semi-transparent overlay circle (a "dimmed/spent" look) while keeping the active ring green, extracts the active-green and the two grey values into exported named constants (single source of truth), and migrates `PieceOverlay.test.tsx` to assert the distinction against those imported constants.

Purpose: A used-up piece reads as greyed-out, never confusable with the bright-green active selection.
Output: Grey moved-this-stage treatment in PieceOverlay driven by exported color constants; migrated PieceOverlay tests proving active-green ≠ moved-grey and correct stacking, asserting against the imported constants (not retyped literals).
</objective>
