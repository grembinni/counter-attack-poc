<objective>
Make `HexGrid.tsx`'s pitch render-skip and every `canSelect*` gate red-card aware through the shared predicate (D-10 item 3), so the client half of BUG-38 matches the server half landed in 42-02/42-03.

Purpose: today the ONLY thing keeping a dismissed piece unclickable is the `onPitch === false` early return at `HexGrid.tsx:761`. Every one of the nineteen `canSelect*` derivations sits below that return, so all of them are masked rather than correct. Two consequences follow: (a) if a code path ever sets `redCarded: true` without `onPitch: false`, the dismissed piece becomes fully interactive again, and (b) the gates read as if they had been audited when they have not — which is precisely the bug class that let BUG-38 ship. `canSelectPenaltyKickTaker` already carries an explicit `piece.redCarded !== true` clause with a comment stating this file's own convention: "a piece must never look clickable and then be rejected." This plan applies that convention uniformly.

Scope boundary (D-01): this is the ONLY plan in Phase 42 that touches `HexGrid.tsx`, and it touches it solely for BUG-38 selection/render gating. All drag-and-drop for this phase lives inside the mid-match roster panel; do not add any drag affordance, drop target or reposition handler to the pitch view here.

Output: `HexGrid.tsx` render-skip keyed on `isActivePiece`, every selection gate explicitly red-card aware, with tests proving both.
</objective>
