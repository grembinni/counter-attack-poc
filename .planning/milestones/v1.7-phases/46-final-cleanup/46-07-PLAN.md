  <what-built>
Phase 46 landed eight user-visible changes across five autonomous plans, all of which passed their automated gates in plan 46-06:

1. **Ball-location ring on three more phases** (46-01) — the white hex ring that already marked the ball during throw-in, goal kick, corner kick, penalty kick and kick-off setup now also renders during `FREE_KICK_SETUP`, `FREE_MOVE_ATTACK` and `FREE_MOVE_DEFENSE`. Free kick was the only restart-setup family missing it; free move qualifies because the engine provably never moves the ball during those phases.
2. **Free Move panel heading** (46-01) — the heading changed from `Free Move!` to `Final-Third Movement!` so it names what triggered the phase. The body line below it is unchanged.
3. **Auto-reselect after an interrupt prompt** (46-02) — when a tackle/steal prompt, GK dive-at-feet prompt, GK box-entry prompt or foul choice resolves and play returns to `MOVE`, the piece that was mid-move stays selected with its movement ring, instead of being deselected and needing a re-click.
4. **Match Speed moved into Advanced Settings** (46-03) — the Match Speed button group is no longer a standalone always-visible section on the game settings screen; it is now a row inside the Advanced disclosure, alongside Fouls / Booking / Injury. Its buttons, icons and colors are unchanged.
5. **Free Kick kicker copy** (46-03) — the Free Kick panel now states how the kicker is chosen and names the locked kicker, in the same voice and format the Penalty Kick, Corner Kick and Throw-In panels already use. Free-kick stage mechanics were deliberately not changed.
6. **Standard-mode bench** (46-04) — a non-Draft room now starts with 5 placeholder substitutes per side (one GK, DEF, MID, FWD, ST), wearing jersey numbers 12-16. Previously standard rooms had an empty bench and the substitution screen had nothing to offer. These are deliberate generic placeholders; per-team authored benches are a later milestone.
7. **Valid-move hex tint consistency** (46-05) — the rule that every movement pattern tints its valid-move hexes the same way is now an explicit, documented exception set rather than phase names buried inline in a boolean. Behaviour is intended to be unchanged unless 46-05's summary reports otherwise.
8. **Pitch player card badge size** (46-05) — the team badge on the pitch player card dropped from 56px to 48px to match the roster card and the bench card, which already agreed with each other.

  <how-to-verify>
Start the app and open two browsers (or one browser plus one private window) so both sides of a match are controllable. Use the project's normal dev-run command; create a room in browser A and join it with the room code in browser B.

**Check 1 — Match Speed relocation.** On the Game Settings screen, before opening Advanced: confirm there is NO Match Speed control visible. Click `Advanced` to expand. Expect: Match Speed now appears inside the drawer, in the left column below Fouls / Booking / Injury, as the same three coloured icon buttons as before. Select a non-default speed and start the match; confirm the match runs at the speed you picked.

**Check 2 — Standard-mode bench.** Create the room in Standard (non-Draft) team mode. Once the match starts, open the substitution screen. Expect: 5 substitutes on your side, one each of GK / DEF / MID / FWD / ST, with jersey numbers in the 12-16 range (NOT duplicating any starter's 1-11), each showing a name, a flag, and a full stat block — not a blank or zeroed card. Perform one substitution of an outfield player. Expect: the substitute takes the field at the outgoing player's hex and appears in the action log. Then try to substitute the bench GK into an outfield slot — expect it to be rejected with the existing GK-parity message.

**Check 3 — Card layout alignment.** Open three surfaces and compare: click a piece on the pitch to open the player card, open the roster/lineup screen to see a roster card, and open the bench carousel to see a bench card. Expect: the team badge is the same size on all three, the stat grid is 3 columns of the same 6 stats on all three, and name / role chip / jersey number sit at the same relative positions. Report any size, spacing or border that still looks off between the three.

**Check 4 — Ball ring during free kick.** Cause a free kick (commit a foul, or use whatever route is quickest given your settings). During `FREE_KICK_SETUP`, expect: a white ring on the hex holding the ball, present through every repositioning stage, in addition to the existing gold "place the kicker here" ring. The two are different concepts and both should show on that hex.

**Check 5 — Ball ring during free move.** Move the ball into a final third to trigger the free-move window. Expect: a white ring on the ball's hex throughout `FREE_MOVE_ATTACK` and `FREE_MOVE_DEFENSE`, and the panel heading reading `Final-Third Movement!` rather than `Free Move!`. This is the check most worth a sceptical eye — free move was a planner judgment call, not a research finding. If the ring reads as noise during open-play-feeling repositioning, say so and it will be reverted for that phase pair only.

**Check 6 — Valid-move hex tint consistency.** Select a piece and note the tint of its valid-move hexes during ordinary movement. Then trigger the other movement pattern types the executing agent names when presenting this check (high pass move, first-time pass move, GK kick move, goal kick move, corner kick final setup, free move) and compare. Expect: the same tint colour and opacity in every one of them. The executing agent will also tell you which phases deliberately look different and why — confirm those, and only those, differ.

**Check 7 — Auto-reselect after an interrupt.** Start moving a piece that has more than one hex of pace, and move it far enough to trigger a tackle/steal prompt (or a GK dive-at-feet / GK box-entry / foul choice prompt) mid-movement. Resolve the prompt — either choice. Expect: when play returns to MOVE, the piece you were moving is still selected and its movement ring is still showing, so you can continue moving without re-clicking it. Repeat for at least one other prompt type if convenient.

**Check 8 — Kicker/thrower selection consistency.** Run each restart type that has a taker: Free Kick, Penalty Kick, Corner Kick, Throw-In. Expect: each panel tells you how the taker is chosen and, once chosen, names them in the same format. Free Kick will still work differently mechanically — you walk a player onto the kick spot rather than clicking then confirming — but its wording should now explain that clearly and name the locked kicker the same way the Throw-In panel names the thrower. Report if the four still feel like four different patterns rather than one family.

For each check, report `pass` or describe what you saw. A partial pass ("ring shows but only after the first stage") is more useful than a bare fail.
