<objective>
Restructure `GameSettingsScreen`'s match-rule toggles from a single always-visible vertical "Match Rules" stack into a collapsed-by-default **Advanced** disclosure containing a two-column grid, and collapse the triplicated Fouls-dependency logic into one shared derivation used at render time and confirm time.

Purpose: SETTINGS-05 (collapsed-by-default Advanced section), SETTINGS-06 (two-column grid), SETTINGS-07 (one shared derivation for the Fouls grey-out). This plan deliberately handles the **five existing toggles only** — it does not add the Referee Leniency row, which plan 44-03 slots into the right column. Splitting it this way means the layout change is verifiable in isolation against the existing test suite, and 44-03 becomes a pure additive insert rather than a simultaneous restructure-plus-add.

Output: a working disclosure, a two-column grid with a reserved slot for Leniency, and one `deriveFoulDependents` helper replacing three independent `!fouls` derivations.
</objective>

This task is a behaviour-preserving refactor — the existing test file must pass untouched after it, which is the proof of preservation.
