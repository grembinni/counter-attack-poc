<objective>
Implement the server-authoritative decline mechanic: intercept the tackle/steal duel inside
`applyMove` when the toggle is on, hold the defending manager's decision in the new
`TACKLE_STEAL_PROMPT` phase, and resolve it in a new `applyTackleStealChoice` engine function
that implements D-01's sequential per-defender queue, D-02's tackling-descending order and
D-03's "the sequence only ends on a possession change or a foul stoppage" rule.

Purpose: this is the phase's core rule. 43-RESEARCH.md Pitfall 1 confirms there is no existing
multi-defender resolution to extend (`gameEngine.ts:1248` hardcodes `defenders[0]`), so the
queue is genuinely new logic, and Pitfall 3 warns that the toggle check must sit at the very top
of each effect block or some duel paths will resolve immediately regardless of the toggle.

Output: a working decline/attempt state machine with no UI yet — the socket surface and panel
are 43-05's job.
</objective>
