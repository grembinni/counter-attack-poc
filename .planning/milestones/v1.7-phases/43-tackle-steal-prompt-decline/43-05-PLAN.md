<objective>
Give the decline mechanic its player-facing surface: a `GAME_TACKLE_STEAL_CHOICE` socket handler
that rolls the duel dice server-side and calls `applyTackleStealChoice`, an
`emitTackleStealChoice` store action, and a `TackleStealPromptPanel` that structurally mirrors
`GkDiveAtFeetPromptPanel` per D-05.

Purpose: 43-04 built a state machine no player can reach. This plan wires the only path into it,
with the five-step guard shape every other two-button prompt handler in this codebase already
uses.

Output: a playable Attempt/Decline prompt.
</objective>
