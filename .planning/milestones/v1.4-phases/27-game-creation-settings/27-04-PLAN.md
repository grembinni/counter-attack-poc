<objective>
Convert the interactive Match Speed picker on both pre-game screens into the read-only info-subheader treatment, and add the Draft-mode settings summary line. In Standard mode the speed is displayed read-only (DRAFT-02, D-07); in Draft mode a single summary line "Speed | Team Type | Draft Pool" replaces the speed control (DRAFT-03, D-09). Both screens use one consistent read-only element; the draft summary string is formatted once in App.tsx so the screens never touch `DraftPoolId` formatting.

Purpose: DRAFT-02 moves speed selection off team-selection (it now happens only on the 27-03 settings screen); DRAFT-03 shows the locked settings summary. Consistent with D-03 (settings locked after confirm), no edit-back affordance is added.

Note (known open item): `TeamSelectionScreen.tsx` is currently unreachable dead code in the live app — every path routes through `UniformSelectionScreen.tsx` since Phase 22. D-07 explicitly names both files, so both are converted for consistency and test coverage, but `TeamSelectionScreen.tsx`'s conversion has no live-app user-facing effect today. This plan does not attempt to fix or resolve the dead-code situation (out of scope).

Output: new `settingsSummary.ts` formatter, both screens converted (+ their tests), and App.tsx prop threading.
</objective>
