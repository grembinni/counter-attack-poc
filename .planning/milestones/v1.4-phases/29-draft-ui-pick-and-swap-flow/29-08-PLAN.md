Close the client-side portion of the 29-06 gaps, all within `packages/client` (no server files touched — runs in parallel with 29-07):

1. **Bench is not a carousel** — `BenchCarousel.tsx` renders a plain `flex-wrap: wrap` row (`.benchCarousel`). Add drag-end resets and gate the Confirm button until the lineup is complete (mirrors 29-07's server `LINEUP_INCOMPLETE` guard).

Purpose: Deliver the required bench carousel UX, legible cards, and a drag interaction that never wedges on stale state.
Output: Reworked `BenchCarousel`, widened card CSS, hardened drag-state handling + Confirm-gating in `LineupAssignmentScreen`, plus component tests.
