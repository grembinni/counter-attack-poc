<objective>
Fix BUG-24: scope Undo to the current phase/stage. Undo must never reach across a turn or
FREE_KICK_SETUP stage boundary, and the Undo button must be disabled when there is nothing
to undo in the current phase.

Two defects are addressed:

1. The client `canUndo` selector has no guard for FREE_KICK_SETUP with an empty
   `freeKickPlacedPieceIds`, so the button can appear enabled at the start of a stage
   (folded todo `free-kick-setup-undo-not-implemented.md`).
2. The server-side undo-boundary behaviour for FREE_KICK_SETUP and cross-slot MOVE must be
   locked with regression tests so the fix cannot silently regress.

Purpose: Prevent illegal cross-turn / cross-stage undo and align the button's disabled
state with actual undo availability (BUG-24, D-03/D-04/D-05).
Output: FREE_KICK_SETUP `canUndo` guard on the client + a server regression suite for undo
scoping.
</objective>
