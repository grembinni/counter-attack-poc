<objective>
Make draft-pack player uniqueness match-wide instead of per-round (BUG-34 / D-06, D-07, D-10).
A player may appear in at most ONE pack across all 6 rounds / 12 packs of a match.

Purpose: this deliberately reverses Phase 30's documented D-18 ("a card CAN reappear in a
different round, since discarded/unpicked cards are never tracked match-wide"). The user
confirmed the reversal during `/gsd-discuss-phase` despite the supply-exhaustion tradeoffs.

Output: a persistent `matchUsedIds` `Set<string>` threaded through `generateDraftPacks`' round
loop and into both candidate resolvers, the stale D-18 comment corrected, and the server's
integration invariant tightened from per-round to match-wide.

Scope boundary: this plan does NOT add the same-pool tier cascade (D-08) or the common-only
cross-pool restriction (D-09) — those land in Plan 36-03. After this plan, the existing
unrestricted cross-pool backfill still absorbs any shortfall the match-wide dedup creates, so
every selectable pool combination must keep generating a full match without throwing.
</objective>

<interface_contracts>
Signatures changed by this plan (all module-private except `generateDraftPacks`, whose public
signature is UNCHANGED so `draftPacks.ts` / `draftSession.ts` need no edits):

- `resolveGkCandidates(selectedUnion: PoolPlayer[], fallbackChain: readonly DraftPoolId[], neededCount: number, matchUsedIds: ReadonlySet<string>): PoolPlayer[]`
- `resolveTieredCandidates(selectedUnion: PoolPlayer[], fallbackChain: readonly DraftPoolId[], round: Extract<RoundConfig, { kind: 'tiered' }>, matchUsedIds: ReadonlySet<string>): TieredPoolPlayer[]`
- `generateDraftPacks(selectedPools: DraftPoolId[], rng: RandomIntFn): { pool: TieredPoolPlayer[]; packs: DraftPack[] }` — unchanged.

Note the resolvers take `ReadonlySet<string>`: they may only READ the match-wide set. Only
`generateDraftPacks` itself mutates it, and only from cards actually dealt (Pitfall 5).

Existing constants/helpers relied on (unchanged): `DRAFT_ROUNDS`, `PACKS_PER_ROUND` (2),
`FALLBACK_POOL_ORDER` (`['mls','original']`), `assignTiers`, `shuffle`, `drawFromPool`,
`buildTierPoolsForRound`, `sortSlotsRarestFirst`, `tierSupplyMeetsNeed`.
