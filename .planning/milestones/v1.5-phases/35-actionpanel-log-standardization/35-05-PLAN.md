<objective>
Replace `ActionPanel`'s single generic waiting message with per-phase text that names the
acting side and the action being awaited (D-09), and bring the four remaining help-text
outliers into the two-line title-plus-detail shape every other phase already uses (PANEL-01).

Purpose: PANEL-01 requires one consistent format and tone across every game phase.
`ActionPanel` currently ships one shared `waitingPanel` constant whose detail line says
"Waiting for opponent..." in all thirteen waiting states, while `FreeKickSetupPanel` already
demonstrates the better pattern (`{Attacking|Defending} team is repositioning…`). Separately,
three phase states break the two-line convention: the PASS/KICK*OFF chooser and the
pass-target prompt use a bare single-line `.phaseLabel`, and `FREE_MOVE*\*` puts a full
explanatory sentence in the title slot.

Output: a `waitingPanel(detail)` function with thirteen phase-specific detail strings, a
`waitingHelperBlock` shared with HEADER's already-confirmed branch, four restructured help
blocks, and two CSS classes removed once unreferenced.
</objective>
