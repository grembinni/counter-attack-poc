This repo already owns formatting via Prettier (`pnpm format:check`) and CSS validity via `vite build`; extending the full standard config would surface Prettier-owned stylistic violations unrelated to THEME-02 and could block CI on formatting noise (and leaving it installed-but-unused would trip the Phase-32 knip gate).
