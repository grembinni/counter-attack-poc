### Per-team accent contrast derivation (THEME-04)

`TEAM_CONFIGS[teamId].palette.uiColor` in `packages/shared/src/teamConfig.ts` **stays raw/unchanged** (D-04) — 14 teams' brand colors are untouched at the source. The AA-safety adjustment happens **only** inside the new `deriveAaAccentColor()` function (`packages/client/src/hooks/useTeamColors.ts`), which feeds `GameBoard.tsx`'s `--team-accent`/`--home-accent`/`--away-accent` CSS custom properties.

**Contract for the derivation function:**

- **Threshold:** `4.5:1` (WCAG AA, normal text) applied uniformly — do not split 3:1/4.5:1 by usage context. Simplest, safest choice for this codebase (per RESEARCH.md Open Question 1 recommendation).
- **Both directions must pass**, since both are live rendering contexts in the current code (RESEARCH.md Pitfall 3):
  1. `contrast(derivedColor, '#121212' /* new --color-bg-page */) >= 4.5`
  2. `contrast(derivedColor, '#ffffff' /* --color-text-inverse */) >= 4.5`
- **Only adjust colors that actually fail** (D-03) — a team color passing both checks today must be returned unchanged, byte-for-byte.
- **Adjustment method:** HSL lightness step-search (darken or lighten in fixed steps, e.g. ±2% lightness per iteration) until both directions clear 4.5:1, preserving hue/saturation as closely as possible so the adjusted color still reads as "the same team color, just AA-safe" rather than a desaturated/generic gray.
- Library: `wcag-contrast` (`hex()` function) — do not hand-roll the luminance formula (see RESEARCH.md Don't Hand-Roll).

**Known-light `uiColor` values expected to require adjustment** (from `teamConfig.ts`, informational — not exhaustive, contrast-check script is the source of truth):

| Team      | `uiColor` | Note                                                               |
| --------- | --------- | ------------------------------------------------------------------ |
| Crew      | `#FEE500` | Bright yellow — near-certain AA fail on white-text-on-bg direction |
| Xolos     | `#FF75A8` | Pink — likely fails at least one direction                         |
| Nashville | `#F5CC26` | Bright yellow-gold — likely fails                                  |

### Accent reserved for

`--team-accent` / `--home-accent` / `--away-accent` (and their AA-derived values) are reserved **exclusively** for:

- Scoreboard team-name/number coloring (`GameBoard.module.css` `.accentTeam` and related classes)
- CTA button background/border states that are team-branded (e.g. hover states in `ActionPanel.module.css`)
- Any other existing `var(--team-accent)` / `var(--home-accent)` / `var(--away-accent)` consumer already present in the 17 chrome CSS Modules

No new consumers of `--team-accent` should be introduced by this phase — it is a value swap plus a new derivation layer, not a redesign of which elements carry the accent.
