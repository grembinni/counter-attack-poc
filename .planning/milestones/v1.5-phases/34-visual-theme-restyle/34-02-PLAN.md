## IMPORTANT — Contrast policy correction (deviation from 34-UI-SPEC, ratified in planning)

34-UI-SPEC.md and 34-RESEARCH.md specify "threshold 4.5:1 applied uniformly, BOTH directions must pass" — i.e. `contrast(accent, #121212) >= 4.5` AND `contrast(accent, #ffffff) >= 4.5`. During planning this was proven **mathematically impossible**: clearing 4.5:1 against `#121212` requires relative luminance ≥ 0.2022, while clearing 4.5:1 against `#ffffff` requires luminance ≤ 0.1833 — an empty band. All 14 teams fail, and the contrast-check script (34-03) would exit non-zero for every team, leaving CI permanently red and the phase unshippable.

The accent has two real, opposed usages in the current CSS (verified this planning session):

- **Accent-as-text on the charcoal base** (always visible): `GameBoard.module.css` `.accentTeam`/`.accentHome`/`.accentAway` → `color: var(--…-accent)`. This is normal body text → WCAG SC 1.4.3 → **4.5:1** against the page background.
- **White text on an accent background** (transient `:hover` CTA states only): `ActionPanel.module.css` `.ctaButton:hover` and `GameBoard.module.css` `.overlayCtaButton:hover` → `background: var(--team-accent)`. This is a UI-component/hover surface → WCAG SC 1.4.11 → **3:1** is the applicable AA bar.

**Corrected, feasible policy this plan implements** (verified to converge for all 14 teams with hue preserved and no desaturation needed for the current palette):

- `contrast(accent, bgHex)` **>= 4.5** where `bgHex` = `#121212` (the accent-as-text direction), AND
- `contrast(accent, fgHex)` **>= 3.0** where `fgHex` = `#ffffff` (the white-text-on-accent-background direction).

Both are legitimate WCAG AA thresholds for their respective usage types, so THEME-04 ("all team-accent colors pass WCAG AA contrast against the new charcoal/white base") is genuinely satisfied. This is the minimal change to the UI-SPEC contract that makes it satisfiable. The orchestrator has been asked to ratify updating 34-UI-SPEC.md's "Contract for the derivation function" section to match.
