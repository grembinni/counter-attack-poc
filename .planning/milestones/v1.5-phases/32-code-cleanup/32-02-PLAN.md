<objective>
CLEANUP-02 (part 1 of 3): Create the two new consolidation hooks under `packages/client/src/hooks/` (a net-new directory, D-03) that the rest of the phase migrates call sites onto: `useTeamColors.ts` (team accent-color derivation) and `useMyTeam.ts` (player-slot → team derivation). Each file follows the **pure-function-core + thin-hook-wrapper** pattern so the same logic is callable from React component bodies (via the hook) AND from non-React contexts — loops, module-level helpers, and Zustand action bodies (via the pure function). This split is mandatory: naively exposing only a hook would break Rules of Hooks in ActionLog.tsx and be uncallable inside useGameStore.ts (Pitfalls 1 and 2).

Purpose: The color and team-slot logic is currently duplicated across 3 + 8 files with two subtly-different `myTeam` semantics. One canonical source removes that drift and gives Wave 2 a single import target.
Output: `useTeamColors.ts`, `useMyTeam.ts`, and their co-located unit tests — no call sites migrated yet (that is Plans 32-03 and 32-04).
</objective>
