<objective>
Establish the chrome design-token layer (THEME-03, D-06/D-07) and implement the reference `--team-accent` runtime-injection pattern on the GameBoard root. This is the contract plan for all chrome-color work: it creates `packages/client/src/styles/tokens.css` with every chrome token (values frozen to today's deep-blue theme) and demonstrates both the CSS-Module `var(--token)` migration and the runtime team-accent CSS-variable pattern on the busiest in-game view.

Purpose: Create the single source of truth for chrome colors so Phase 34 becomes a pure token-value swap, and remove per-component team-accent lookups from GameBoard per THEME-03.
Output: New `tokens.css` (imported once in `main.tsx`); GameBoard migrated to tokens + runtime accent variables; a GameBoard test asserting the `--team-accent` variable derives from the active team.
</objective>
