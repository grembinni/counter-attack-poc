# Milestone v1.2: Team Identity & Core Fixes

**Status:** ✅ SHIPPED 2026-07-03
**Phases:** 15–18.4 (10 sub-phases)
**Total Plans:** 52

## Overview

v1.2 transformed Counter Attack from a working prototype with placeholder visuals into a named-squad, team-branded, rule-complete game. Four real teams with badges and jersey patterns replaced hardcoded placeholders; player rosters were populated from fc_stats.csv with a full team-selection lobby; seven rule-correctness defects were fixed and the Counter Attack v1.4.1 action model was fully aligned (16 plans across Phase 17.1); messaging, logging, replay, and dead-code cleanup rounded out the polish. Phase 18's four sub-phases fixed 21 additional bugs and delivered 8 UX enhancements including game-speed selection, end-turn confirmation dialog, final-third markers, tooltips, and a transient EventBanner.

## Milestone Summary

**Key Accomplishments:**

1. Four named teams (Cozmos, Xolos, City, Crew) with badge PNGs, jersey patterns, and CSV-seeded player rosters replaced the hardcoded placeholder squads
2. Full team-selection lobby: home player picks first, away player chooses from remaining three; badge and colors propagate throughout the match
3. Seven rule-correctness defects fixed (BUG-01..05, MOVE-06, PASS-02) and the full Counter Attack v1.4.1 action model aligned across 16 plans (Phase 17.1)
4. Offside detection (sticky, team-relative, all pieces) + free-kick restart flow implemented (OFFSIDE-01/02)
5. 21 bug-bash items fixed across Phases 18.2/18.3 including replay frame visibility, duplicate-logic consolidation, and movement-state-machine correctness
6. 8 UX enhancements: game-speed selector, end-turn confirmation dialog, final-third red boundary lines, stat/action tooltips, transient EventBanner

**Decisions Locked:**

- badgeFile in TeamConfig is filename key only — static Vite import in TeamBadge gives content-hashed URLs
- TEAM_CONFIGS[TEAM_DEFAULTS[piece.teamId]] is single color source of truth across all surfaces
- firstTimePassCarrierId added to GameState (mirrors highPassCarrierId) to prevent self-pass reclaim exploit
- computeLooseBall rewritten to use cube-coordinate unit vectors (parity-independent), eliminating systematic NE/SW overshoot
- FTP_MOVE_ENABLED=false const disables FIRST_TIME_PASS_MOVE phase by default (delivered directly)
- checkHalfEndOnTackle exported function gates half-end on tackle/steal success paths using addedTime, no re-roll

**Issues Deferred:**

- OFFSIDE-01/02 human UAT checkpoint (two-tab live verification) not formally closed before Phase 17 was accepted
- GK_KICK ball delivery invisible during post-game replay (GK_KICK missing from REPLAY_ELIGIBLE_TYPES; tracked in todos)
- KICK_OFF_SETUP persistent shot-path hex shading (root cause not identified via static analysis; tracked in todos)
- LOOSE_BALL_LAND has identical replay-invisibility gap as GK_KICK (pre-existing)

**Technical Debt Incurred:**

- Three response-move test fixtures in useGameStore.test.ts carry stale `movementSlot: 'ATTACKER_4'` (currently inert but same fixture-hygiene defect class as BUG-09)
- `validateHeading` OUT_OF_RANGE/CONSECUTIVE_HEADER rejections silently discarded at 2 call sites (HEAD-01 2-hex range unenforced for GAME_HEADER_CONTESTANT)
- HIGH_PASS_MOVE has same missing-repositioning-exclusion defect as FIRST_TIME_PASS_MOVE had pre-17.1-16 (deferred parallel finding, documented in 17.1-16-PLAN.md)
